# 灵境 LingJing

> 一间课室：**人类是体验者，给 AI 上课；AI 负责激发，人负责判定。**

## 一句话

**灵境是一间虚拟课室：你（人类体验者）来给 AI 上课、传授任何知识 / 经验 / 技能；AI 学生负责激发——从各个角度向你提问，逼你把所知的讲清；课后由你（人）自己判定讲没讲透，并带走你的思考、盲区与总结。**

## 这是什么

- **人类是体验者，也是传授者。** 在这里你不需要假装成别人，只需做自己最擅长的给予者——把你的任何知识、经验、技能教给 AI。
- **AI 负责激发，不负责判定。** AI 学生从多个角度抛出探测式提问，让你在「被请教、被追问」中重新审视自己的所知：哪里讲顺了、哪里其实没想清、哪里有盲区。
- **人负责判定。** 所有「讲没讲透 / 懂没懂」的结论，由你课后逐条自己下；AI 不评任何理解度、不伪造「学会了」。
- **产出属于体验者自己。** 课后你得到：① **思考**（在回答追问中梳理出的想法）② **盲区**（被问住、讲不清的地方）③ **总结**（一份属于你自己的讲授纪要）。

## 功能

- **自由开课**：输入任何主题 / 教案，无需预设结构，教什么都可以。
- **AI 多学生**：数名 AI 学生从不同角度实时提问、追问。
- **持久作品**：你的讲授与笔记作为作品留存在世界（`World=⟨S,R,M,T⟩`）中。
- **课后抽屉**：四感总结、知识地图、盲区提示（KL 缺口）；数据不删、不对外。
- **可选 LLM**：设 `LINGJING_OR_KEY`（OpenRouter 兼容）启用 AI 说人话；不设也能跑（走兜底文本）。

## 作用（为什么值得来）

- **把「教」变成一面镜子**：你以为自己懂的，在 AI 的追问下暴露出模糊与缺口。
- **零成本圆「传授欲」**：被需要、被请教的满足感，无需真实学生、无需场地。
- **自我认知**：在给 AI 上课的过程中，看清自己的知识边界与思维盲区。

## 怎么跑

- 依赖：Node 22+
- 启动：`node server.js`（默认端口 8080；可用 `PORT` 环境变量改端口）
- 打开 `public/index.html`，或访问 `http://localhost:8080`
- 可选 LLM：设环境变量 `LINGJING_OR_KEY`（OpenRouter 兼容）启用 AI 学生说人话；不设也能跑（走兜底文本）

## 结构

| 路径 | 作用 |
| --- | --- |
| `server.js` | HTTP 服务（`/api/roster`、`/api/class/start`、`/api/class/reply`） |
| `teacher.js` | 课堂编排：探测生成、纪要、收益统计（纯计数，非判定） |
| `teaching.js` | 已停用占位函数（不评分，留作接口占位） |
| `world.js` / `physics.js` / `rom.js` / `index.js` | 课室世界、物理 / 数学框架、入口 |
| `public/` | 课室前端 |
| `tools/` | 测试 |

## 合规红线

- 显著提示「在与 AI 而非自然人交互」。
- 不做情感依赖、不评学生理解度、不伪造「学生学会了」。
