# 灵境 LingJing

> 一间课室：**人类是体验者，给 AI 上课；AI 负责激发，人负责判定。**
> 定位一句话：人类是体验者（也是传授者），AI 是激发者（不学习、不评分、不判定），判定权永远归人。

---

## 一句话

**灵境是一间虚拟课室：你（人类体验者）来给 AI 上课、传授任何知识 / 经验 / 技能；AI 学生负责激发——从各个角度向你提问，逼你把所知的讲清；课后由你（人）自己判定讲没讲透，并带走你的思考、盲区与总结。**

最深的价值流程不是「铺功能」，而是**盲区照见反思环**：人讲 → AI 多角追问 → 人答 → 人自判 → 带走思考 / 盲区 / 总结。

---

## 一、这是什么（角色契约，不可漂移红线）

| 角色 | 职责 | 不做什么 |
|---|---|---|
| **人类（体验者 / 传授者）** | 讲出自己的知识 / 经验 / 技能；回答学生的追问；**逐条自判「答到了没有」** | 不把判定外包给机器 |
| **AI 学生（激发者 / 镜子）** | 抛探测（真实文本）、照出人类讲解里没讲透的口子 | **不学习、不评分、不声称「懂了」、不做「学生→分数」边** |
| **判定者 = 人类本人** | 课后读并排清单，心里「咯噔」处即口子 | 机器不代判 |

**架构不变量（代码层强制）：** 世界 `World=⟨S,R,M,T⟩` 中**不存在「学生→分数」关系**；一切「懂没懂 / 答到了没有」的自动判定，灵境一律不做。机器只做两件它真做得到的事：① 对人类讲解文本做确定性弱信号检测（定位可能漏讲的地方）；② 把学生原话与先生原话逐条并排（镜子）。

## 二、理论（为什么这样设计）

### 2.1 门徒效应与可教代理（基石）

- **门徒效应（Protégé Effect，Chase et al. 2009）**：当人以为自己在教一个「可教代理」时，投入与效果显著优于「为自己学」；人会社会性看待 AI、产生责任感；**失败发生在 AI 学生身上，不打击传授者自尊**——这是体验安全感的基础。
- **可教代理范式（Betty's Brain / Biswas et al. 2005；ALTER-Math / Xing et al. 2025）**：人类作为老师、AI 作为学徒，在传授中完成知识重构。ALTER-Math 已服务 50 000+ 初中生，证明「AI 当学生」可规模落地（其原话：「AI 还不是可靠的老师，但 AI 是出色的学生」）。
- **LLM 门生（Kucharavy et al., BEA 2025）**：把 LLM 当「会犯错的学生」辅导，算法课中成功诊断其错误者平均 +0.72 分（1-6 制），挂科率 28%→8%。

### 2.2 认知科学七理论 → 盲区环子机制

| 理论 | 在盲区环的落点 |
|---|---|
| 认知冲突 / Impasse（VanLehn 2003） | 学生职责 = 制造 impasse（卡住），不是配合点头；探测即 impasse 引信 |
| 生成效应（Slamecka & Graf 1978） | 人「答」这步必须真生成，不能只听 |
| 最近发展区 ZPD（Vygotsky） | 探测指向「人类刚讲到、但还没讲透」的要点 |
| 认知负荷（Sweller） | 每学生每轮只抛一枚探测，六类错开，不堆 |
| 自我决定（Deci & Ryan） | 无外部评分才保内在动机 |
| 对话式教学 / 心理操作标签（Chi 2009） | 六类探测句式即心理操作标签 |
| 认知学徒制（Collins, Brown & Newman） | 「AI 理解笔记」把学生思维外化给人类看 |

### 2.3 第二批：隐性知识 / SECI / 心理安全 / 心流 / 社会临场感 / 检索练习 / 知识诅咒

- **隐性知识（Polanyi）**：「我们所知的，多于我们所能言说的」；经验、手艺、判断靠定义式提问萃取不出来，必须靠案例 / 边界 / 权衡类提问——这是灵境真正的护城河。
- **SECI（Nonaka & Takeuchi 1995）**：外化（隐性→显性）是最难一步；灵境核心抓手就是帮人把脑子里的经验、直觉转化成可描述的显性表达。
- **心理安全（Edmondson 1999）**：「不被评判」才敢暴露模糊认知——灵境靠「不评分、不纠错、只倾听+提问」结构性实现。
- **心流 / 难度校准（Csikszentmihalyi 1990）**：提问难度随人类响应模式动态调（流畅→更深；卡住→退回澄清）。
- **社会临场感 / 身份拟人（Xia et al. 2026）**：拟人化提升效果靠激发积极情绪；AI 学生有稳定名字 + 记忆连续性（低人格化），不挡人。
- **检索练习 / 测试效应（Roediger & Karpicke 2006）**：「传授」本身 = 持续检索练习；体验中不给反馈，课后笔记触发自发现。
- **知识诅咒（Camerer 1989）**：专家默认前提、跳背景；AI 学徒持续扮零基础，追问隐含假设。

### 2.4 幻觉→优势：我们的反转（含独立判断）

大模型「随机预测下一个词、一定会出错」的弱点，在灵境里不是 bug 而是 feature——AI 学生天然冒出「没跟上 / 理解岔了」的提问，恰好逼人去解释、去补漏，正是门徒效应。

**独立判断（不附和）：** 这个反转成立，但**只有当随机性被导到真缺口上时才成立**。光靠原生 LLM 自由发挥，随机性会退化成「提问抓不住重点、揪无关细节」（抖音一线实测）。灵境的解法不是消灭随机，而是**用确定性薄弱点定位层把随机性导流**——AI 学生的困惑落在该落的口子上。

> 佐证：让 LLM 像真学徒一样会卡住，本身是活跃研究子领域（engineering fallibility）。Jin et al.（CHI 2024，AlgoBo 的 Reflect-Respond pipeline）用知识态锁死 LLM 上限；Miller & Bosch、Yang et al. 提出约束式 prompt / 工程化知识缺口——共同印证「原生 LLM 太全能反而毁掉学徒角色，须用确定性约束导流」。

## 三、原理（产品怎么运转）

### 3.1 盲区照见反思环（最深价值流程）

```
人讲(Teach) ──▶ AI 多角追问(Ask/Probe) ──▶ 人答(Respond) ──▶ 人自判(Judge=人) ──▶ 带走(思考/盲区/总结)
                  ▲                                                          │
                  └──────────── 下一轮：新问题来自上一轮没答透的口子 ────────┘
```

- **Teach**：公理3 注入，人类任意知识 / 经验 / 技能。
- **Ask / Probe**：六类探测（反例 / 边界 / 正例 / 区分 / 机制 / 应用），由学生产出真实文本。
- **Respond**：人类回话，原文回填到对应探测。
- **Judge**：只发生在人脑，课后逐条读并排清单。
- **带走**：课堂纪要 + 讲授收获 + AI 理解笔记 + 跨课无知地图。

**深度指标（不评分，只计数 / 看增长）：** 单课顿悟数 + 课后盲区总结准度（人自判）+ 跨课个人无知地图增长。

### 3.2 设计公式（MVP 阶段，不含任何评分）

```
盲区环深度 D  ∝  Σ(人类真生成的回答)            // 生成效应：人答得越多，环越深
              + Σ(被并排的"他问/你答"原文对)     // 镜子：原话越多，自判越准
              − 0 × (任何"学生理解度"量)          // 该量已删，不参与

薄弱点定位 L  = detectWeakPoints(讲解文本)        // 确定性，可复现，跨场景取值不同
探测定向       = argmax_{未消耗薄弱点} severity → (conceptIdx, probeType)
```

### 3.3 防漂移红线

1. **任何加场景 / 功能，先证「它深化了盲区照见反思环」。** 不铺职业、不堆 3D、不加学生性格评分。
2. **判定权永不泄漏**：不得新增「学生→分数」边、不得复活自动判定 / 学生自评。
3. **数学量必真动**：新增任何量（severity / 覆盖率 / 熵），须有测试证明跨场景取值不同；恒为 0 / 恒定值 = 摆设，删除。
4. **对外表述诚实**：研究引用 ≠ 产品复现；不声称「知道 AI 学生懂没懂」「知道你答到了没有」。
5. **数据不删不对外不评分**：笔记 / 探测 / 无知地图全留世界，课后抽屉默认收起，课堂上永不出现内部指标。

## 四、我们自己的方法（工程实现）

### 4.1 P0-1 确定性薄弱点定位层（`teaching.js` · `detectWeakPoints`）

盲区环里「AI 从哪角度问」**不靠模型猜人类哪里漏讲**，而靠对人类讲解文本做**可解释、可复现**的弱信号检测，钉出「可能讲漏 / 讲偏」的位置，喂给探针调度。

四类理解漏洞信号（确定性正则，跨场景取值必不同）：

| 信号 | 含义 | 严重度 |
|---|---|---|
| `jargon` 用术语未解释 | 人类可能「甩术语」，听众接不住 | 2 |
| `jump` 逻辑跳跃 A→C | 缺了中间的 B，听众跳不过去 | 3（最大盲区） |
| `abstract` 具体→抽象 | 从例子突然飞到概念，听众悬空 | 1 |
| `parrot` 用原话非自己话 | 人类没用自己的理解讲，只是复述 | 1 |

调度规则：每轮优先取「严重度最高且未消耗」的薄弱点 → 其要点定为该学生盯的靶、信号→策略映射定为探测类型；无未消耗薄弱点时退回轮转，保证概念覆盖。效果：人类文本里「用术语没解释」的要点，会被学生用「举个生活例验证」逼；「逻辑跳步」的要点，会被「中间怎么发生的」逼。问题**落在该落的口子上**。

> 防摆设：信号 / 严重度须跨不同讲解文本取不同值（`tools/test_weakpoint.mjs` 用术语密集 / 跳步多 / 平实三段文本断言计数与类型不全相同）。

### 4.2 P0-2 AI 理解笔记（镜子机制，`teacher.js` · `aiNotes`）

可教代理研究的硬结论：镜子该把「学到的」（=人类教的）暴露回给人类，**含它可能理解错的地方**——人类读到「它理解岔了」，才照见自己哪句讲歧义了。

`aiNotes` 是**确定性镜子**，全用真实文本拼装：旧想法（进课堂前的误解）+ 记下的先生原话 + 还没搞清的（没收到回答 / 还在问的口子）+ 一句自我点检。不声称 AI 有理解、不评分、不删不对外。

### 4.3 架构：世界 + 探针调度

- **世界 `World=⟨S,R,M,T⟩`**（`world.js`）：公理3 人类内容只注入；`relatedness(humanId)` = 关系图度中心性（意义供给）；无「学生→分数」边。
- **探针调度**（`teacher.js`）：P0-1 定向优先，轮转兜底，保证概念覆盖与口子钉准。
- **六类探测**（`teaching.js` `PROBE_TYPES`）：反例 / 边界 / 正例 / 区分 / 机制 / 应用。

## 五、差异化（vs 真实竞品，2026-09 联网核验）

| 竞品 | 范式 | 是否评分 / 判定人 | 与灵境 |
|---|---|---|---|
| **Axiom Flow** | 教 AI 学生 Sam（故意带错）；Sam 考 10 题 MCQ，**分数 = 你的成绩** | **评分** | 同范式但反向：它把「教」变成考试 |
| **Chrysalis** | 双模式：AI 导师 + 教 AI 门生；门生模式带 quiz 评估 | **评分** | 同范式但保留评估层 |
| **ALTER-Math** | 初中生教「弱化」AI 解代数；挣积分 | gamification，非对人评分 | K12 数学 + 积分，定位不同 |
| **抖音「费曼 Prompt 玩法」** | 单轮 Prompt 扮演「零基础小白」 | 无（但常出戏 / 抓不住重点） | 灵境要解的「临时扮演不稳定」 |

**头号差异化（对外口径）：** 当前「教 AI」范式里，**只有灵境把「只提问、绝不评分」做成架构不变量**（世界无「学生→分数」边）。Axiom Flow / Chrysalis 都默认「教完要考一下」，用分数替代人的自判；灵境的差异化正是「不替代，把判定的咯噔留给人」。

## 六、怎么跑（自托管）

- 依赖：Node 22+
- 启动：`node server.js`（默认端口 8080；可用 `PORT` 环境变量改端口）
- 打开 `public/index.html`，或访问 `http://localhost:8080`
- 可选 LLM：设环境变量 `LINGJING_OR_KEY`（OpenRouter 兼容）启用 AI 学生说人话；不设也能跑（走兜底文本）

> 本仓库为**自托管发布**：别人 clone 后用各自密钥跑，不触发公网合规 regime。若作为公网公共服务运营，须先过合规红线（见第八节）+ ICP 备案 + TLS。

## 八、合规红线

- 显著提示「在与 AI 而非自然人交互」。
- 不做情感依赖、不评学生理解度、不伪造「学生学会了」。
- 公网运营前须过：AI 生成标识、OpenRouter 出境同意 / PIPL、匿名 Cookie 同意 + 留存删除、ICP 备案 + TLS、安全三刀、存储 TTL。
