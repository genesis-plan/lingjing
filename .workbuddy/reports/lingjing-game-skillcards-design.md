## 一、我的独立判断：这个想法站得住，而且有硬实证

结论先说：**想法好，不是拍脑袋，是被学习科学反复验证过的范式。** 但"游戏感"和"技能卡片"必须建在**真实的知识迁移信号**上，否则就是装饰、会骗人。

### 1.1 外部论文实证（已联网核实，非凭记忆）

| 理论 / 论文 | 关键证据 | 对本产品的意义 |
|---|---|---|
| **Betty's Brain**（Biswas, Vanderbilt；可教代理范式） | 学生教虚拟 agent 概念图，agent 用定性推理链回答；SRL 组在迁移测试（氮气循环）上显著更好；学生"知道角色不是活的，但投入叙事就学得更好" | 直接证明"教一个 AI 学生"能激活学习——我们的 5 个 AI 学生 + 人类当教师，正是这个范式 |
| **Protégé Effect / 教中学**（Kobayashi 2019 元分析，28 研究） | 效果量 **准备教 g=0.35，实际教出 g=0.56**；互动教 > 非互动教 | "让人讲出来"这一步最关键——我们的课堂强制人类开口讲，正中靶心 |
| **Knowledge-telling bias**（Roscoe & Chi 2007 / 2008） | 只复述不建构 = 无深度学习；必须真"讲出来 + 答 why"才有效 | 我们的 `addressScore`（教师回答是否碰到学生疑问）+ 盲区诊断，正是逼"建构"而非"复述" |
| **Knowledge Distillation**（Hinton 2015） | teacher→student，soft targets + temperature 编码"dark knowledge"（老师的不确定性本身含信号） | 把"讲解→卡片"数学化为**蒸馏**：卡背 = 教师要点（软目标）+ 学生原话（谁卡在哪=不确定性信号） |
| **Flow Theory**（Csikszentmihalyi） | 挑战-技能平衡 = flow channel；8 维度（清晰目标/即时反馈/专注/自控…） | "游戏感"的数学定义 = 用 挑战(概念难度) vs 技能(讲解完整度) 校准到 flow 通道 |
| **Skill/Knowledge Card**（间隔重复 + 主动回想） | 一卡一事；艾宾浩斯间隔；主动回想吸收率显著提升 | 课后卡片组用 1→2→4→7→15→30→60 天间隔阶梯，把讲授压成长期记忆 |

### 1.2 诚实的提醒（别把好事说满）

- **知识-telling 陷阱**：如果课堂只让人类"念一遍"，按 Roscoe & Chi，不会有深度学习。我们的价值靠"学生追问 why + 教师必须回应"这环——已用 `addressScore` 量化，不能省。
- **LLM 信号上限**：没真 LLM 时，R / σ² / 学生"没懂"都是启发式，**不能当客观测评**、不能谎称"全员学会了"。卡片与度量里都标了"启发式/非客观"。
- **"游戏感"不是花哨**：真正的 flow 来自"难度刚好匹配你当前表达力"。我们用心流徽章把这件事**可读化**，而不是用特效糊弄。

## 五、追加（2026-09-11 用户定调）：重点是人类——四感 + 理论感总结

用户原话："实现那个想法，用上人类所有的数学，给人类使用者，最后做一份总结吧，我们的重点不是那5个AI学生，是人类，让人类在这次使用中获得体验感，游戏感，实践感，最后一个总结用来提升他自己的理论感。"

### 5.1 新增 `public/summary.mjs`（课后总结引擎，纯数学、可 Node 验）

把一堂课**重组为数学结构**，覆盖主要分支（每项都有可计算值 + 一句"对你意味着什么"）：

| 数学分支 | 数学对象 | 在本产品里算什么 |
|---|---|---|
| 逻辑 / 证明论 | 前提 → 推理 → 结论 | 把要点按逻辑角色分类 → 你的讲解的证明骨架是否完整 |
| 图论 | 依赖图：根/叶/深度/枢纽/环 | 概念依赖关系；枢纽概念先讲；环=循环论证风险 |
| 概率 / 贝叶斯 | BKT 后验掌握度 | 学生对每个概念"最可能已解开"的概率 |
| 信息论 | 概念熵 H_j；KL(你的强调‖学生达成) | 你讲得最多、学生吃得最少的概念 = 重点没落到学生身上 |
| 分析 / 微分方程 | 热传导 FTCS；遗忘曲线 dR/dt=−R/S | 知识扩散与冷却；算出每张卡的复习时刻 |
| 线性代数 | P ∈ [0,1]^{N×M}；E=Σu² | 整堂课 = 一张知识状态矩阵在迭代；热场能量二次型 |
| 代数 / 关系 | 世界 ⟨S,R,M,T⟩ | teach 边数 + 作品数 = 你的讲解被接进世界模型的证据 |
| 控制论 / 优化 | Flow 通道（挑战−技能） | 把难度校准到你的表达力（游戏感的数学定义） |
| 统计 | E(t) 与 σ² | 课堂整体解开度与离散度（软信号） |
| 组合 / 序列 | 艾宾浩斯间隔复习序列 | 按你的掌握度算出的最快复习时刻 |

输出「**四感**」：体验感（课堂真发生）× 游戏感（flow 贴合）× 实践感（你动手的量）× **理论感**（知识被讲成多大一张有结构的地图），再给「下一步（把实践变理论）」。
