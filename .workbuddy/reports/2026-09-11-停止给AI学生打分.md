# 停止给 AI 学生「打分」——决策与 9 组标定数据

> 日期：2026-09-11
> 范围：灵境·课室（teacher.js / teaching.js / 前端 / docs）
> 结论：**删除一切对「AI 学生理解了多少 / 被接住了多少」的自动判定**，判定权交回人类（课后逐条看他问的 / 你答的）。

## 一、为什么停

产品定位（用户拍板）：**软件为人服务，不是为 AI 服务**。AI 学生是镜子与提问者，不是学习者——
它没有脑子，谈不上「学会了多少」。之前代码里两类数字，源头都没有真值：

1. **学生自评理解度**（旧 R / P(t) 矩阵 / E(t) / σ²(t)）：那是模型采样出来的 0~1 小数，
   是对「任何东西」的观测都没有的随机数。在它上面求均值、方差、熵，等于给随机数化妆。
2. **「接住」自动判定**（caught / caughtRate / blindSpots / conceptCaught）：用
   *教师回答与学生问题的 2-gram 重叠* 判定「答到了没有」。下面 9 组标定证明它基本是噪声：
   **答得好的反而得 0，敷衍的复述学生用词反而得高分**。

用噪声下判断，比不判更糟。于是：机器只报**事实**（抛了几枚探测、收到几枚回答的原话），
「答到没」留给人读完清单后自己判。

## 二、9 组标定数据（复现旧 2-gram 判定，真实跑出来的分）

判定口径复现：`score = |教师回答的二字片段 ∩ 学生探测的二字片段| / |学生探测的二字片段|`
（只取汉字，去标点）。分数越高＝教师回答越「像接住了」学生的问题。

| # | 学生探测（原话） | 教师回答 | 2-gram 分数 | 人类判定 | 判定对不对 |
|---|---|---|---|---|---|
| 1 | 那要是把「阳光的作用」反过来说，还成立吗？ | 阳光只是能量来源不是物质本身；反过来说没有阳光植物改用别种能量也能活，所以阳光是饭本来就不成立。 | 0.313 | 答到 | ❌ 错（噪声） |
| 2 | 水和二氧化碳到什么份上就不算数了？界线在哪儿？ | 反应要光叶绿素合适温度；低于零度酶停摆长时间无光就转不成糖，这就是边界。 | 0.000 | 答到 | ✅ 一致 |
| 3 | 糖和氧气我在生活里见过，可我不确定是不是同一回事 | 你家里发酵的面团水果放久冒的泡都是糖被微生物处理放气的现象，和光合放氧同源但不是一回事。 | 0.136 | 答到 | ✅ 一致 |
| 4 | 那要是把「阳光的作用」反过来说，还成立吗？ | 好的，你问的阳光的作用反过来说成不成立我们下次再讲。 | 0.563 | 敷衍 | ✅ 一致 |
| 5 | 水和二氧化碳到什么份上就不算数了？界线在哪儿？ | 水和二氧化碳你问的界线这个问题问得很好，水和二氧化碳的界线我们以后讨论。 | 0.300 | 没答到 | ✅ 一致 |
| 6 | 糖和氧气我在生活里见过，可我不确定是不是同一回事 | 糖和氧气你生活里见过的同一回事这个我记下了后面再讲。 | 0.455 | 敷衍 | ✅ 一致 |
| 7 | 阳光的作用跟另一个说法到底差在哪？我老搞混 | 阳光的作用和另一个说法差在一个是能量来源一个是物质原料，你搞混的正是这两层。 | 0.526 | 答到 | ❌ 错（噪声） |
| 8 | 水和二氧化碳为什么会这样？中间到底发生了什么？ | 这个问题很深，建议你自己查资料。 | 0.000 | 没答到 | ❌ 错（噪声） |
| 9 | 换成另外一种情况，糖和氧气还算数吗？ | 换成别的能量源比如某些细菌用硫化氢照样能合成类似糖的物质，所以糖不是唯一产物但把无机物变有机物这条还成立。 | 0.067 | 答到 | ✅ 一致 |

- 答到的 5 组里，3 组分数 ≤ 0.27（机器判「没接住」），另有 2 组分数偏高（0.31 / 0.53）却也是「答到」——
  说明分数只捕捉「是否复读学生原词」，不捕捉「是否真答到」；
- 敷衍 / 没答到的 3 组里，2 组分数 ≥ 0.33（机器判「接住了」）。
- **score 与人类判定（答到=1）的 Pearson 相关系数 r = -0.288**（接近 0 且方向为负：分数越高，反而更可能是敷衍 / 没答到）。

这就是「好回答 0.000、敷衍 0.333」的来源：教师一换词，重叠清零；敷衍话复述学生原词，重叠拉满。
**拿它当「接住率」写进产物，是在用噪声假装度量。**

## 三、删了什么 / 留下什么

已删除（代码 + docs 一致）：
- 学生头顶的理解度进度条 / understand 事件 / R 值
- finalP / avgR / H / conceptCaught（产物里的假指标）
- completeness / resolved / caught / caughtRate / judged / blindSpots（自动「接住」判定）
- E(t) / σ²(t)（软信号，标注停用）；teaching.js 里 initP / fallbackUnderstand / teachingEffect / classEntropy / addressScore / overlapScore 标为「已停用占位」

留下（机器真数得出来的**事实**，一个判断性的数都没有）：
- `gains`：points（你讲几要点）/ probes（学生抛几枚）/ answered·open（几枚收到回答·几枚没回，纯计数）
- `probes` + `probeByConcept`：每枚探测的**原话**与本地复核的六类类型，按要点归拢
- `summary.pairs`：逐条并列「他问的 / 你答的」（你没回的进 openQ）
- 课后《课堂纪要》《我的收获》——五生发言拼装的作品，不写「我们弄明白了」
