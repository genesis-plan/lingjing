## 一、外部研究结果（竞品 / 论文 / 规律）

### 1.1 同类产品：这个方向已经被验证过，而且规模不小

| 产品 / 项目 | 做法 | 关键数据 |
|---|---|---|
| **ALTER-Math**（Univ. of Utah 等六校） | 中学生当老师，教"虚拟同学"解代数题；**故意用"弱" LLM** 促发批判性思考 | 5 万+ 用户；6000 人前后测，学习增益 **1.56×** |
| **Betty's Brain / Teachable Agents**（Stanford AAA Lab） | 学生教虚拟学生 Betty | 研究者 Schwartz 原话：**"这不是电子游戏。6-8 小时后它完成它的工作；它不替代东西，它让东西变好"** |
| **Teach'a'Topic**（硕士项目，48 人调查） | 从"找人教"转向"教 AI" | **88% 认可教别人的价值，只有 8% 真做过**；障碍＝怕被评判 + 对不上时间 + 反馈质量 |
| **Teach the Bot** | 你教 bot，bot 故意下错结论、要求举例 | 用进度条显示"bot 理解了多少" |
| **Explique / Algorithm Apprentice**（Wang et al.） | LLM 当学徒，546 名学生 11 周 | **解释导向的对话预测更少错误提交；外部内容复用预测更多错误** |

**对我们最有价值的两句话**（可直接进对外说明）：
- ALTER-Math 负责人 Chenglu Li：**"AI 还没成为可靠的老师，但已经是优秀的学生。"**
- Schwartz 关于不可成瘾：**"6-8 小时就完成它的工作；它不是电子游戏。"** ← 与我们的合规红线（不做情感依赖/沉迷）**同向**，是外部背书而非自说自话。

Teach'a'Topic 的 88%/8% 落差，正是灵境用"AI 当学生"消掉的东西：**社交风险归零**。

### 1.2 生产性失败（productive failure, Kapur）——本次最大的一块新增

| 证据 | 数值 |
|---|---|
| Kapur 2014（9 年级，随机对照） | 先挣扎组后测显著胜出，**d = 2.25** |
| Sinha & Kapur 2021 meta 分析 | 概念理解与迁移上稳定占优 |
| ETH Zurich 线性代数（650 人，一年期） | 提前做"失败任务"的学生通过率高 **20%** |

**四个机制（4A）**：Activate 激活先验 → Awareness 意识到缺口 → Affect 更想听讲解 → Assembly 与讲解对接。
**硬条件（缺一就白做）**：
1. 问题必须**真的超出当前能力**；
2. **至少两次真实尝试**（Kapur：consolidation 只在两次尝试之后）；
3. 必须有**足够先验**——否则不是生产性失败，是干瞪眼；
4. 讲解必须**接在自己的尝试上**（原话："failure without consolidation is just failure"）。

### 1.3 顿悟（insight / aha）——"峰"有结构，所以能被检测

- **四阶段**：Preparation → Incubation → **Insight** → Verification。
- **四特征**：强烈正面情绪 / 突然且不可预测 / **在"卡住"之后更显著** / 主观体验。
- **机制**：顿悟来自**元认知预测误差**——"我们对自己的表现感到意外"的那一刻。
- 可用的技术手段：**制造认知失调 → 解决**（先摆错误假设）；**完形闭合**（碎片逐渐成整体）；**违反预测**；节奏控制（揭晓前故意延迟）。
- ⚠️ 风险：顿悟可能带来"把错误信息当成真的"的偏差 → 需要元认知配套。

### 1.4 排课（间隔重复）——不再用固定序列

- **FSRS（Jarrett Ye 2022；Anki 23.10 起默认）**：DSR 模型 `R(t,S) = (1 + F·t/S)^DECAY`，F=19/81、DECAY=−0.5。
- 基准（5 亿+ 条 Anki 复习记录）：同等留存下比固定乘数**少 20-30% 复习量**。
- ⚠️ 边界：FSRS 需 ~1000 次复习才能拟合个人参数，之前回退默认值。
- **交错练习（Dunlosky 2014 meta）**：混着复习显著优于按主题成块复习。

## 二、落地：三个新模块（纯数学、可 Node 验、无 DOM/网络依赖）

### 2.1 `public/preclass.mjs` —— 课前生产性失败引擎

**它解决的问题**：灵境原本只有"你讲 → 学生问 → 课后总结"，缺了**讲之前**那一段——而那是收益最大的一段。

| 数学 | 用来算什么 |
|---|---|
| 集合论 / 覆盖 | 先验激活度 = 尝试对讲解概念集的覆盖率 |
| 组合 / 相似度 | 尝试多样性 = 两次尝试词项集的 **Jaccard 距离** |
| 信息论（KL） | 缺口意识 = **KL(你的注意力 ‖ 讲解重点)**，对齐越好越接近 1 |
| 逻辑 / 因果连接词 | "真实尝试"判据（含因果/反事实/假设推理，排除"不知道"） |

**放行闸门**（不是打分器）——六档判定：`no-attempt` / `not-genuine` / `one-attempt` / `shallow` / `no-prior` / `ready`。
只有 `ready` 才放行讲解；其余情况给**具体动作**（"换个完全不同的角度，不是改写上一条"）。

**探针四形态**：反事实（把因果反过来）/ 边界（推到极端）/ 机制（中间那一步）/ 迁移（换个领域）。
设计成"**凭直觉能开始、但缺知识就答不全**"——正是 Kapur 要的那种题。

> ⚠️ 过程中修掉一个"数学摆设"：最初用"缺失概念的权重熵"算 awareness，实测**恒等于 0**（缺失概念权重相近 ⇒ 熵恒接近上界）。换成 KL 对齐度后才有区分度（合格 0.733 / 一次尝试 0.605 / 离题 0）。

### 2.2 `public/journal.mjs` —— 跨课个人知识库

**它解决的问题**：原本"上完一课卡片就散了，下次来是全新的"，没有复利。

- **真 DSR 排期**（替换写死的 `[1,2,4,7,15,30,60]`）：
  - `R(t,S) = (1 + F·t/S)^DECAY`
  - 反解目标留存：`t = S/F · (r^(1/DECAY) − 1)`，默认 r = 0.9
  - 初始稳定度 = f(掌握度, 难度)；复习更新用 SM-2 易度因子骨架 + 难度后验
- **交错队列**：按 R 升序（最快会忘的最前），再按课题**轮转重排**，保证相邻卡来自不同课题。
- **成长叙事**：概念数 / 课题数 / **记忆资产 = Σ S（天）** / 复习次数。用事实陈述，**不做夸奖也不做恐吓**。
- 数据只落 **localStorage（本机浏览器）**，不联网、不上传。

**自洽性已验**：S = 0.5 / 3 / 30 / 200 排出的间隔，代回 `R(t,S)` 全部精确回到 0.9。

### 2.3 `public/insight.mjs` —— 顿悟峰检测（峰终定律里的"峰"）

**它解决的问题**：峰终定律说记忆由"峰"和"终"决定；"终"（课后总结）早就做了，"峰"一直空着。而"峰"**不能用音效/称号伪造**（SDT 过度理由效应会反噬内在动机）——只能**检测**。

| 数学 | 用来算什么 |
|---|---|
| 时间序列一阶差分 | 跃迁幅度 ΔR |
| 自回归残差 | **意外度** = 元认知预测误差 |
| 生存分析 | 卡住持续了多少轮（stuckRounds） |
| 对数尺度 | 峰强 ∝ log(1+卡住轮数)：卡越久，突破越强（且**不能顶格写死**） |

**最重要的设计是诚实**：检测不到峰就**如实说没有**，并给出方向（"说明讲解清楚但没制造出张力——峰值往往来自先让卡住"）。
反向防伪：光说"哦原来是这样"但 R 没动 → **不算峰**（防文案骗过检测）。

### 2.4 `teacher.js` 提示词：工程化易错性（engineered fallibility）

- **问题**：大模型默认输出"专家级、流畅、正确"——这恰好是"挣扎的新手"的**反面**。
- **依据**（Miller & Bosch, "Prompting for teachability"）：**基于约束的提示**（明确强制产生错误）比人格提示、误解提示、不确定性提示都**可靠得多**。
- **改法**：从"你有个可能错的想法"（人格/误解式）改为"**本轮你必须说一个具体的错**：把某样东西当成另一样、把因果说反、把条件记漏"。
- 同时加**引擎化知识缺口**（Yang et al.）：学生手里有"只有他经历过的一手小事"，让老师**必须解释**，不能含糊带过。
- 两行格式契约保持不变（未破坏 `test_llm_wiring.mjs` 全部断言）。

## 六、还缺一个真正的"峰"

现在能**检测**峰，但还不能**制造**峰。研究指出峰来自"认知失调 → 解决"，可落地的做法是：
**讲之前先让学生抛出一个自信的错误判断**，老师纠正的那一刻就是张力释放点。

这需要 LLM 在场（学生要"自信地说错"），所以**排在拿到额度之后**，且必须先实测提示词是否真的产生"自信的错误"。
