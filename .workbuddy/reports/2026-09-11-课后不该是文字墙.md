# 课后不该是一堵字 —— 灵境课室「界面变成文字」的诊断与修复

> 触发：用户 2026-09-11 反馈「界面怎么变成文字呢，不是课室吗」
> 结论：**课室没变，变的是课后。** 课后面板当时是一份 **3103 字 / 3.48 屏**的纯文字文档。
> 全部改动**未提交、未推远程**。

---

## 一、先量，再说（不猜）

| 位置 | 实测 | 判定 |
|---|---|---|
| 一打开 | 3D canvas **1416×761 = 视口 100%**；讲台条 820×88（6.7%）；AI 身份提示 268×84（2.1%） | ✅ 铁律没破，就是课室 |
| 点「随手一课」 | 课前探针卡 720×98（**≈5.4% 屏**，底部一条，学生脸没被挡） | ✅ 不是挡板 |
| **课后** | 内容高 **2646px / 视口 761px = 3.48 屏**；正文 **3103 字** | ❌ **一屏接一屏的字** |

课后各块占高（改造前，2646px 总高）：

| 块 | 高 | 占比 |
|---|---|---|
| 最后一课总结 | 683px | 26% |
| 纪要正文 | 570px | 22% |
| 技能卡片组 | 385px | 15% |
| 我的收获 | 321px | 12% |
| 知识库 | 214px | 8% |
| 顿悟峰 | 149px | 6% |

**诊断：不是"某一块太长"，是课后整体被写成了文档。** 而且其中三块的数学（峰=一条时序曲线、复习队列=一条时间轴、课前对照=一次左右 diff）在最后一步被**拍平成了文字**——等于把算出来的数学丢掉。

## 二、改了什么

### 1) 课室不许被抹掉（直接回应"不是课室吗"）
`#work` 背景 `rgba(8,6,4,.88)` → 径向渐变 `0.42 → 0.82`。
面板本身仍是米色不透明（不影响阅读），但**四周留出课室**，人一眼知道自己还在教室里。

### 2) 课后分节：首屏留给"这一课发生了什么"
7 个块改成 `<details class="sec">`，**默认只展开 4 个**（峰 / 课前对照 / 收获 → 3 个 open；纪要 / 理论总结 / 技能卡片 / 知识库 → **默认收起**）。

顺序也重排了——原来最值得回看的两块（峰、课前对照）排在第 5、6 位，被埋在折叠线以下；现在提到最前。

### 3) 该是图的，画成图（纯内联 SVG / DIV，零依赖）

| 块 | 原来 | 现在 |
|---|---|---|
| 顿悟峰 | 一句话"卡了 N 轮之后…" | **R 随轮次曲线**：细线=5 名学生各自，粗线=全班均值，红圈=检测出的峰，虚线=0.45"还糊涂"判据 |
| 复习队列 | 5 列表格 | **对数刻度时间轴**：颜色即课题，交错一眼可见；逾期条最短+标红；**刻度尺**（1天/7天/30天/90天/1年）+ **锚绝对天数**（跨课可比） |
| 课前对照 | 上下两段文字 | **左右两栏**：左「你课前的那两次尝试」，右「先生讲的 · 你碰到了几个」（✓ 绿标签 / ○ 红标签）+ 摸到比例条 |

### 4) 长段解释收进 `<details class="why">`
"这些数字怎么算的 / 这个对照怎么来的 / 为什么这么算 / 卡片是怎么来的 / 这份总结的诚实边界"——5 处，默认不摊开。

### 5) 补上一条**回到课室**的路
原来课后只能「再上一课」＝刷新重来。现在右上角 **← 回到课室** 收起回顾，右下角留 **看课后回顾** 入口，双向都通。

## 四、修掉的 3 个真问题（都不是"新功能没做完"，是我自己写错的）

1. **曲线看着像图坏了**：兜底模式下全班 R 全程 ≈0，3px 的均值线贴在 0 网格线上，视觉上等于空白。
   → 把数值直接写进图内（`全班均值 0.00`），并在 `max R < 0.15` 时显式说明"曲线贴着底不是图坏了"（有跃迁时**不**挂这句，已加断言防它变成常驻话术）。
2. **均值标注与横轴刻度打架**：标注写在线的末端会和轮次号同一行、把最后一个轮次号压掉。→ 平线时挪到图内右上。
3. **逾期卡与"1 天后"长度相同**：`Math.max(1, 负数天数)` 把逾期 −3 天压成了 1 天。→ 逾期直接压到 0（最短+标红＝最该现在复习）。
4. **刻度按本组最大值归一化 → 长度不携带量级信息**（新断言抓到）：三条全是 `100%`，因为这一课的三张卡恰好都是"3 天后"。
   归一化下，上一课的 100% 和这一课的 100% 不是一回事，跨课没法比。→ 改成**锚绝对天数**（1 天 12% / 7 天 35% / 30 天 46% / 1 年 100%），并加**刻度尺**把条长翻译成天数（带对齐断言：刻度尺与轨道左右偏 0px）。
5. **旗舰图在常见情况下根本看不见**：复习时间轴原来只在"今天有到期卡"时才画，可第一课刚上完所有卡都在几天后到期 ⇒ **用户第一次打开永远看不到这张图**，只剩一句"今天没有到期的卡"。
   → 没到期就画"接下来该复习的"，并明确标注（不是把未到期的当到期偷偷显示）。加断言：第一课 `.tl-row ≥ 1`。
6. **我插入辅助函数时把 `function renderWork(ev){` 吃掉了**，靠"抽取内联 `<script type=module>` → `node --check`"当场抓到——这个语法自检步骤值得固化。

## 六、⚠️ 诚实边界

- **峰曲线在无 key 兜底模式下是贴底的**，因为兜底学生语料让 R 全程 ≈0。这**不代表真实 LLM 下也会这样**——有额度时需重验曲线在真 LLM 下的形态。
- 「首屏 ≤2 屏」是我这轮设的**回归护栏**，不是学习效果指标；它只证明"不再回退成文字墙"。
- 折叠默认收起是**取舍**：资料性内容（纪要/卡片/理论/知识库）多一次点击，换来首屏是曲线+对照。
- 未提交、未推远程。是否提交、是否继续收（例如把顶部的"未配置 LINGJING_OR_KEY"状态条改成给用户看的人话）等用户拍板。
