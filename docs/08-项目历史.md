## 二、每个阶段的关键事实

### A · 框架期（09-04 ~ 09-07）

- 首个提交 `c0852b1 init`（09-04），随后 `07c6adb` 五层框架双轨实现（JS + Python/NumPy）。
- `c346058`（09-07）三维热传导虚拟仿真落地 —— 遗留至今的 `physics.js` / `rom.js` / `public/framework3d.mjs` 都出自这一时期。
- `5191ab4`（09-07）修掉三个"测量陷阱"：样本内背答案 / 跨距错配 / 污染基。**这次修复定下了后来的习惯**：任何量先问"它有没有真值来源"。

### B · 物理与定律学习期（09-08）

单日 27 次提交，是仓库最密集的一天。内容包括：

- 从轨迹反推力律（SINDy / STLSQ）→ 证明"物理层可学习"；
- `RealWorld3D`（原点＝地球中心、中心反平方引力）→ 用学出的律替换硬写常量做双轨验真；
- `verify_sensor` / `verify_ground` / `verify_dynamic` 三组"真实世界条件体检"：证明**观测 ≠ 真值**（欠采样 + 噪声下朴素差分崩、RTS 平滑恢复）；
- 约束电池与耦合可行性判定（M1–M11 全部落成可执行断言）；
- `lingjing-mcp.js`：把世界包成 MCP stdio 服务供 AI Agent 调用；
- `lerobot_bridge`：吃真实机器人录制数据（LeRobot）的桥。

**结局**：`01556ff`（09-09）`scrap simulation/constraint direction — restart from representation essence` —— **整段推翻**，相关文件全部从仓库删除。

> **这段历史的价值**：它留下的纪律（双轨验真、观测≠真值、fail-closed）在课室阶段全部继承了下来。例如 `retention.js` 的匿名可去重键、`questioning.js` 的"LLM 只当嗓音"、`summary.mjs` 的"只报可计算量"，都是那套纪律的延续。

### C · 重定位期（09-09）

- 09-09 推翻物理方向，重新锚定为**体验空间**：进来零门槛体验他喜欢的职业 / 兴趣。
- 存档标签 `pre-rewrite-20260909` 即标记这一天。

### D · 课室 MVP 与"原罪"（09-10 ~ 09-11）

- 落地"虚拟 + 5 个 AI 学生 + 课后『他问的 / 你答的』清单"，纯前端 + 极简 Node 服务。
- 期间实装了自动判定层：知识状态矩阵 `P(t)`、教学效果 `E(t)`、差异度 `σ²`、`finalP`。
- **09-11 重大变更**：`510810d feat(灵境): 人判新契约落地——停止给 AI 学生打分`。
  这些量的源头是"模型采样出的学生自评理解度"或"2-gram 文本重叠噪声"——**是我们不可能知道的真值，属假理论**，全部移除，不再计算也不再展示。

> 这是整个项目最重要的一次删除。此后"不评分"从**产品态度**升级为**架构不变量**（世界模型里没有"学生 → 分数"这条边）。

## 五、两条一直没变的线

1. **判定权归人。** 从 09-11 删除自动判定层起，任何"AI 判断你答到了没有"的量都被移除，并写进世界模型不变量。
2. **诚实优先于好看。** 宁愿让曲线只画"你写了几个字"，也不画一条基于假数据的"悟性上升曲线"；宁愿在文档里写"未做 / 已删除"，也不写"路线规划中"。
