## 二、数据实践（当前实现）

| 项 | 做法 | 代码位置 |
|---|---|---|
| **账号** | 无。不注册、不登录、不采手机号邮箱 | — |
| **LLM 密钥** | 仅服务端环境变量（`LINGJING_*_KEY`），**从不进前端、不进仓库** | `server.js` / `llm.js` |

| **留存数据的用途** | 只在**运营方离线脚本**（`tools/retention_report.js`）里读，**绝不进用户屏幕** | `retention.js` 注释红线 |
| **`sessions/` 是否入库** | **不入库**（`.gitignore` 已忽略） | `.gitignore` |
| **外发数据** | 只有"要让学生说人话"时才把讲解 / 回答文本发给所配置的 LLM 提供商 | `llm.js` |

### 出境提示（重要）

选不同提供商，数据去向不同：

| 提供商 | 端点 | 数据去向 |
|---|---|---|
| `openrouter`（默认） | `openrouter.ai` | **境外**。作为面向公众的服务运营时，须做出境合规评估与用户告知 |
| `zhipu` | `open.bigmodel.cn` | 境内 |
| `siliconflow` | `api.siliconflow.cn` | 境内 |
| `deepseek` | `api.deepseek.com` | 境内 |

**不配任何密钥也能跑**：此时走确定性兜底语料，全程零外发。数据合规要求高的场景，可以用"无密钥模式"或"境内提供商"。

## 三、现状张力（版权人待拍板，工程侧不代决）

1. **LICENSE（禁止复制）与 README（邀请 clone 自托管）不一致。** 要么放宽 LICENSE（例如允许非商业自用），要么收回 README 的邀请。**属法律决策，待版权人拍板。**
2. **是否改开源协议 / 双轨。** 开源钩子能换来分发与采用，商用双轨能保住授权收入；两者取舍是商业决策。
3. **公网运营主体与备案信息。** 若要作为公共服务运营，须先落实 ICP 备案与公安备案；当前仓库未声明。

工程侧只保证：**代码事实与文档一致、口径不夸大、不自造授权条款。**

## 五、合规红线（写代码 / 写文案前必读）

1. **判定权永不外包**：不得新增"学生 → 分数"边；不得复活任何自动判定 / 学生自评。
2. **不做"知道学生懂没懂"的表述**：对外只说"照出你的盲区""把原话并排"。
3. **不声称达到论文效果**：研究引用只是设计依据。
4. **课上不出现内部指标**：一切指标收进课后抽屉、默认不展开；留存数据只给运营方离线脚本看。
5. **密钥只在服务端**，且永不入仓库 / 不入前端 bundle。
6. **数据不删不对外不评分**：学生的探测、人的回答、跨课无知地图都留在世界对象里，归使用者本人所有。
