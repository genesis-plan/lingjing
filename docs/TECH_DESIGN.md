# 技术设计文档：灵境·课室

> ⚠️ **诚实说明（2026-09-11 重大变更）**：本文档已按**当前实际实现**重写。
> 原架构里的 `P(t)` 知识状态矩阵更新循环、`teachingEffect` 算 `E(t)/σ²(t)` 已被**移除**——
> 那是「模型采样出的学生自评理解度」驱动的假理论（详见 `teaching.js` 顶部「停用」说明）。
> 现在服务端**只报事实**，判断交还给人。

## 1. 文档信息
- **版本**: v1.1.0 MVP（2026-09-11 人判契约）
- **最后更新**: 2026-09-11

## 2. 当前系统架构（已落地）

```
┌──────────────────────────────────────────────┐
│  前端（浏览器，原生 HTML/CSS/JS）              │
│   一打开就在教室 · 学生当堂提问 · 课后清单      │
└───────────────────┬──────────────────────────┘
                    │ HTTP POST /api/class/start ·reply (SSE)
┌───────────────────┼──────────────────────────┐
│                   ▼                           │
│  后端（Node 原生 http，零依赖，本机运行）     │
│   server.js → teacher.js(runClassroom)         │
│     ├─ teaching.js  知识模型(纯数学，仅做难度/性格调度) │
│     ├─ world.js     框架世界 ⟨S,R,M,T⟩         │
│     └─ OpenRouter   5学生 LLM（可选，有密钥）  │
└───────────────────────────────────────────────┘
```

> 前端**不渲染任何「AI 学生理解度 / 教学效果 E / 差异度 σ²」**——这些数字已删。
> 屏幕只出现人能一眼懂的东西（谁在问、问了什么、你回没回）。

## 3. 技术选型（当前 MVP）

| 层级 | 技术 | 理由 |
| :--- | :--- | :--- |
| 前端 | 原生 HTML/CSS/JS | MVP 避免框架学习成本，单文件可跑 |
| 后端 | Node 原生 http | 零依赖、本机跑、不过部署税 |
| 知识模型 | teaching.js（纯函数） | 仅做概念抽取 / 难度估计 / 性格调度；**不再算 P/E/σ²** |
| 框架世界 | world.js | ⟨S,R,M,T⟩ 状态 + 确定性并发合并 + JSON 持久 |
| LLM | OpenRouter（默认免费档） | 免费档可验；`LINGJING_OR_KEY` 注入、`LINGJING_OR_MODEL` 可覆盖 |
| 状态管理 | 进程内存 + World 对象 | MVP 无需数据库 |

## 4. 数据流（当前 MVP · 人判契约）

```
1. 用户开课，前端 POST {lesson:"课题::讲解[||概念]"}
2. 后端 teacher.js 解析教案 + 抽取知识点 k_j（≤5） + 估计难度 β_j
3. 每轮：5 名学生按性格抛出「探测」（真实文本问题，类型：反例/边界/正例/区分/机制/应用）
        → 教师回答（或跳过）→ 记为事实：这枚探测你答了 / 没答
4. 全程只数词：gains = { probes, answered, open, points, replies, clarifying, probeLine }
5. 下课产物：probeByConcept（按要点归拢的学生原话） + probes（逐条他问/你答）
           + summary.pairs（他问的/你答的并排） + summary.openQ（你没回的）
           + teacherReportMd（教师专属复盘：讲清了/盲区/术语/费曼）
6. 前端课后把「他问的 / 你答的」清单递给使用者，**答到没由人自己判**
```

> `teaching.js` 里 `initP / fallbackUnderstand / teachingEffect / classEntropy / addressScore / overlapScore`
> 等函数**保留为「已停用占位」**（见文件顶部「停用」段），**不在实时判定链路中**。是否彻底删除待用户拍板。

## 5. 状态管理（当前）
- `World`（world.js）：`S`(实体 Map) / `R`(关系) / `M`(测度) / `T`(时钟)；lesson/note/kstate 均为 artifact 持久留世界。
- 会话状态在单次 `runClassroom` 调用内完成，无跨请求会话（MVP 单课即一请求）。

## 6. 错误处理（当前）
- LLM 调用失败/超时/429 → 自动降级确定性兜底（通用提问 + 预演台词）
- 无 `LINGJING_OR_KEY` → 全程兜底，仍演示完整课堂循环
- JSON 解析失败 → parseLesson 回退默认课题
