## 二、三闸门筛选（AI 擅长 / 技术成熟 / 能实现=不绑死真实物理）

| 类别 | 职业 | 过闸门 | 灵境可交付形态（AI 当什么） |
|---|---|---|---|
| 服务型 | 咖啡师 / 民宿主人 / 向导 / 空乘 | ✅ | AI 当顾客/客人/游客，最稳 |
| 语言创造 | 作家 / 翻译 / 塔罗 / 电台主播 | ✅ 纯语言 | AI 当读者/听众/求问者 |
| 知识探索 | 教师 / 侦探 / 导游 | ✅ 纯语言 | AI 当学生/委托人/游客 |
| 创意视觉 | 演员 / 服装 / 插画 / 摄影 / 化妆 / 室内 | ✅（需文生图） | AI 当观众/模特/客户 |
| 语言/销售 | 律师 / 兽医 / 房产经纪 / YouTuber | ✅~⚠️ | AI 当对手/宠物主人/看房客/观众（兽医需领域知识） |
| 音乐 | DJ / 音乐人 | ⚠️（需音频生成） | 后期内容层 |
| 物理/身体 | 飞行员 / 消防员 / 潜水 / 外科 / 运动员 / 驾驶 | ❌ **物理锁死** | 当前不可交付真实版本 |
| 高压专业 | 护士 / 医生 | ❌ 慎 | 生命伦理+高压，体验空间不合适 |
| 生产工具 | 工程师 / 科学家 / 数据分析 | ⚠️ | 偏生产力，非"体验喜欢职业"拉力 |

**纯语言 9 个最先可做**（仅 LLM=OpenRouter，零额外依赖）：咖啡师 / 民宿主人 / 导游 / 翻译 / 教师 / 侦探 / 作家 / 塔罗 / 电台主播。

## 四、诚实张力（不虚报）

1. **全球 Top 2 最想要（飞行员、消防员）正好物理锁死** —— 它们"想飞/想救人"的浪漫需真实体感，体验空间零物理当前交付不了。故"全球刚需 ∩ 灵境可交付"实际缩到**语言/创造/服务型**子集。对外不能宣称"覆盖全球最想要的职业"。
2. **"全球刚需"是假设非已证** —— 上述调查量的是"梦想/搜索欲"，不是"愿为虚拟体验付费"。须小样本验一个职业的真实留存与付费意愿。
3. **意义层风险仍在** —— 体验要"对他人真实有意义"，单人冷启动靠 AI 当客人/观众/学生兜底；纯独处型（如作家）多人感弱，不与 MVP 首选。

## 五、MVP 决定：教师

**选定理由（用户拍板）**：人体验"教师"职业，AI 当学生，纯语言，全球需求强（多源进前十）。

**原型状态**：`teacher.js` 已跑通 —— 1 人类教师 + 3 AI 学生（人设 小问/阿学/萌萌 各异）课堂 4 轮，真实 LLM 提问，教案 + 12 学生笔记共 13 件作品**持久留世界**。密钥 `LINGJING_OR_KEY` 注入，模型默认 `google/gemma-4-26b-a4b-it:free`（`LINGJING_OR_MODEL` 可覆盖）。

**已解难点**：免费模型泄漏思考过程→清洗（去英文/思考标签/只取首行）；同轮/跨轮重复→顺序生成 + 全程去重 + 显式禁回声 + 12 条兜底语料。

**待扩展**：导游/侦探/咖啡师等纯语言职业复用同一 `student`/NPC 框架；视觉类（演员）待接入文生图。
