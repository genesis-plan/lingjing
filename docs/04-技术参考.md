## 一、总体形态

- **运行形态**：一个极简 Node HTTP 服务（`server.js`）+ 一套零构建的浏览器前端（`public/`）。
- **依赖**：**零第三方依赖**（只用 Node 内置模块 + 浏览器标准 API）。Three.js 已本地化为 `public/three.module.js`，离线可用。
- **运行时**：Node 22+（实测 22.12）。
- **数据落盘**：`sessions/`（课堂世界 JSON + 课后产物 + 留存事件流），已被 `.gitignore` 忽略。
- **数学/物理内核**：`world.js` / `physics.js` / `rom.js` / `graph.js` / `index.js`（确定性数值，可 Node 直接跑）。

### 目录与模块

| 路径 | 作用 |

### 课堂形态（一处容易看错的地方）

`teacher.js` 的 `createSession()` 里写的是 `PERSONALITIES.slice(0, 1)` —— **当前只启用第一名人设（小明 · 好奇型）**，产品口径为「**一面镜子**」（2026-09-18 定案）。`PERSONALITIES` 与前端 `CAST` 保留全部五个人设，是为多生形态留的底层与渲染兜底；`speakersForRound()` 对 `n === 1` 有专门分支（只有一面镜子时每轮都开口）。**不要把"代码里有五个人设"读成"产品有五个学生"。**

## 二、确定性薄弱点定位层（P0-1）

**命根**：盲区环里"AI 从哪个角度问"，**不靠模型猜人类哪里漏讲**，而靠对人类讲解文本做**可解释、可复现**的弱信号检测。

实现：`teaching.js` · `detectWeakPoints(lesson)`

### 五类理解漏洞信号

| 信号 | 含义 | 判定方式（确定性正则 + 跨句比较） | 严重度 |
|---|---|---|---|
| `jargon` | 用术语未解释 | 专业词（…定律 / 定理 / 效应 / 函数 / 熵 / 梯度 / 矩阵…）出现，但同句邻句无解释标记 | 2 |
| `jump` | 逻辑跳跃 A→C | 推理词出现，但前一句没有前提标记（缺了中间的 B） | 3（最大盲区） |
| `abstract` | 具体 → 抽象 | 抽象词（本质 / 规律 / 范式 / 底层…）出现，但本句无生活例 / 数字锚点 | 1 |
| `parrot` | 像照本宣科 | 本句与上一句 bigram 重叠率 > 0.7 且都较长 | 1 |
| `omit` | 该讲未讲 | 概念被点到但未被展开 | 3 |

**高信心缺口优先**：当信号是 `omit` / `jump` 且句子带**定论式口吻**（高信心标记）时，严重度 +1（上限 5），优先钉 —— 这是收益最高的窗口。

### 信号 → 探测策略映射（决定"逼哪个口子"）

```
jargon → example      用生活例验证，逼你把术语落地
jump   → mechanism    问中间怎么发生的，逼你补 B
abstract → counter    举反例，逼你把概念踩回地面
parrot → apply        问怎么用，逼你脱离原文
omit   → bound        问边界条件，逼你说清适用范围
```

调度规则：每轮优先取「严重度最高且未消耗」的薄弱点 → 其要点定为该学生盯的靶、映射出的策略定为探测类型；无未消耗薄弱点时退回轮转，保证概念覆盖。

**效果**：人类文本里"用术语没解释"的要点，会被学生用"举个生活例验证"逼；"逻辑跳步"的要点，会被"中间怎么发生的"逼。**问题落在该落的口子上。**

> **防摆设**：信号 / 严重度必须跨不同讲解文本取不同值。`tools/test_weakpoint.mjs` 用「术语密集 / 跳步多 / 平实」三段文本断言计数与类型不全相同。

## 三、TCMQ 确定性提问引擎

实现：`questioning.js`

**设计铁律（与 P0-1 同源）**：

1. 本模块**只产出「问句规格 spec」**（钉谁 / 什么类型 / 引哪句原话 / 第几层 / 等多久 / 什么姿态）；**LLM 只是"嗓音"**，负责把 spec 用中文说出口。任何"怎么问"的规则都在确定性层落地，不交给模型。
2. 完全不评分、不评判、不纠错 —— 只做"学徒不知而问"的困惑式反射（以好奇提问、请人解释机制、禁为人辩护立场）。
3. 纯函数、可单测、跨输入可复现（`tools/test_questioning.mjs`：25 项断言）。

**六条规则及其实质：**

| 规则 | 实质 |
|---|---|
| 镜面锚定（100% 引用原话） | 中性重述建立信任、维持思考流，逼人自察 |
| 学徒姿态（不知而问） | 以好奇提问、不装懂，结构性安全空间 |
| 六层递进 | 澄清 → 举例 → 因果 → 假设 → 反例 → 元认知，分层攀升 |
| 等待 / 沉默 | 提问后留认知停顿、不抢答（高阶问题尤需） |
| 双轨（显性 / 隐性） | 显性逻辑链 + 隐性场景 · 权衡链（B 轨模板就位，检测待接线） |

**七类探测**（`teaching.js` `PROBE_TYPES`）：

| key | 标签 | 出手句式（hint） |
|---|---|---|
| `counter` | 反例 | 有没有反过来也成立的？我想到一个好像不符合的 |
| `bound` | 边界 | 什么情况下它就不成立了？ |
| `example` | 正例 | 我生活里见过的那件事，算不算？ |
| `distinct` | 区分 | 这两个说法到底差在哪？我总把它们搞混 |
| `mechanism` | 机制 | 为什么会这样，中间是怎么发生的？ |
| `apply` | 应用 | 要是换成别的，会怎样？ |
| `land` | 落地 | **2026-09-18 新增**，薄教案（口号式空话）专用：把先生原话**原样举起来**逼落地——问"这到底什么意思／拿件具体的事说明白"，而不是装作有现成概念可探 |

**探测类型的判定是本地正则复核**（`classifyProbe`）：不采信模型自报的类型；判不出就返回 `null`（`unknown` 计数）——**宁可判不出，也不硬套一类**（硬套＝另一种编）。

## 四、双稿制反思引擎

实现：`public/reflection.js`（`tools/test_reflection.mjs`：87 项断言）

**命根**：**不靠模型替人定稿。**

结构：

```
AI 镜稿三块（全"我"开头，不评价 / 不建议 / 不评分）
  ① 我听到的核心内容
  ② 我还没完全明白的地方
  ③ 我可能理解偏了的地方
        ↓
人五类修改动作：确认 / 改写 / 补充 / 删除 / 转化
        ↓
人定稿三阶（照镜札记）：事实 / 反思 / 行动 / 保留（允许保留困惑）
        ↓
七步流程：镜稿 → 通读 → 五类改 → 三阶定稿 → 朗读(可选) → 确认定稿 → 回看
```

`reflection.js` 是**经典脚本**（挂 `window.LJReflection` 与 `module.exports`），供 `classroom.html` 直接 `<script>` 引入；`public/summary.mjs` 是 ESM 模块。两者混用需注意导出形式（详见 [02 · 使用指南](02-使用指南.md#五测试与真实基线) 的已知问题）。

## 五、AI 理解笔记（P0-2，镜子机制）

实现：`teacher.js` · `aiNotes`

可教代理研究的硬结论：镜子该把"学到的"（＝人类教的）暴露回给人类，**含它可能理解错的地方** —— 人类读到"它理解岔了"，才照见自己哪句讲歧义了。

`aiNotes` 是**确定性镜子**，全用真实文本拼装：

- 旧想法（进课堂前的误解）
- 记下的先生原话
- 还没搞清的（没收到回答 / 还在问的口子）
- 一句自我点检

**不声称 AI 有理解、不评分、不删不对外。**

## 六、世界模型与世界持久化

实现：`world.js`

```
世界 = ⟨S, R, M, T⟩
  公理 1：世界 = 状态空间 + 结构（S 状态 / R 关系 / M 测度 / T 离散时钟）
  公理 3：人类 = 不可计算外部输入（人类的内容不由引擎生成，只能被注入）
```

- **确定性并发合并**：`step()` 按 `agentId` 字典序确定合并 —— **任意提交顺序得到同一个世界**（`index.js` 里有断言）。
- **可插拔内容层**：物理 / 职业 / 学科不属于世界骨架，是内容层（`physics.js` / `teaching.js`）。
- **关系**：`relatedness(humanId)` 用关系图度中心性度量"意义供给"。
- **无"学生 → 分数"边**：结构上不存在，不靠调用方自觉。
- **持久化**：`sessions/<时间戳>-<课题>-world.json`，跨重启留存。

## 七、课前 / 课后 / 跨课：三块"复利"机制

| 模块 | 机制 | 依据（设计依据，非效果承诺） |
|---|---|---|
| `public/preclass.mjs` | **课前生产性失败**：先让你尝试、再讲解；并对"现在放行讲解是不是浪费这次失败"给出**确定性判断**。硬条件：① 问题必须真的超出当前能力 ② 必须有至少两次真实尝试 | Kapur 的 productive failure（PS-I）：先解题后讲解；ETH Zurich 线性代数课程、ALTER-Math 等报告了正向结果 |
| `public/skillcards.mjs` | **课后卡片组**：卡面＝学生当初问你的那句话（逼主动回想），卡背＝你的要点 + 学生原话 | 门徒效应 / 费曼式自测 / Flow 理论 |
| `public/journal.mjs` + `public/rhythm.mjs` | **跨课知识库**：每张卡带记忆参数，按**预测回忆概率**排期；节奏曲线只画"你回了多少字" | FSRS 的 DSR 记忆模型（Difficulty / Stability / Retrievability）；峰终定律 |

### 为什么节奏曲线只画"你写下的字"

`public/rhythm.mjs` 的头注释记录了三次改版：

1. **初版**：检测"学生理解度跃迁（顿悟峰）"—— 理解度来自学生**自评**，是模型采样出的数，没有真值来源；在它上面做一阶差分找规律，等于在噪声里找规律。**废掉。**
2. **二版**：改成"探测有没有被先生的回答接住"（2-gram 文字重叠）。标定 9 组真实问答发现**判定反转**：好回答 0.000（他换了词），敷衍的"好的下次再讲" 0.333（它复述了学生用词）。**废掉。**
3. **现在**：只画关于人类的东西 —— 第 k 轮学生抛出探测器之后，你下一次开口回了多少个字。**它是你写下的字，数得出来，不需要任何判定。**

## 九、LLM 接入

实现：`llm.js`

**选择提供商**：`LINGJING_LLM_PROVIDER = openrouter | zhipu | deepseek | siliconflow`（默认 `openrouter`）。

| 提供商 | 端点 | 默认模型 | 备注 |
|---|---|---|---|
| `openrouter`（默认） | `openrouter.ai` | 免费档降级链 | **境外**；有降级链，429 自动切换 |
| `zhipu` | `open.bigmodel.cn` | `glm-4.7-flash` | 境内，免费档 1 并发 |
| `deepseek` | `api.deepseek.com` | `deepseek-chat` | 境内，低价备选 |
| `siliconflow` | `api.siliconflow.cn` | `deepseek-ai/DeepSeek-R1-0528-Qwen3-8B` | 境内，一个 key 可调多模型 |

**按功能组合的管线**（硅基流动侧，全部为实测筛出的免费档模型）：

```
对话 chat / 语音 ASR (XingChenGSR) / 翻译 (Hunyuan-MT) / 推理 (Xing4.0-29B) / 画图 (Kolors)
combo：语音 → ASR → 翻译 → 推理 → 对话 → 输出
```

> ⚠️ 推理模型（`DeepSeek-R1-0528-Qwen3-8B` / `Xing4.0-29B`）答案可能在 `reasoning_content` 字段，`oneCall` 已兜底读取。

**不配密钥也能跑**：走确定性兜底语料（`PERSONA_FB`），流程完整、体验降级。**数据合规要求高的场景推荐无密钥模式或境内提供商。**

## 十、HTTP 接口

服务默认端口 `8080`（`PORT` 可改）。**无鉴权**，定位为本机 / 内网。

| 方法 | 路径 | 说明 |
|---|---|---|
| `GET` | `/` | 2D 课室页面 |
| `GET` | `/classroom3d.html` | 3D 课室（Three.js 已本地化） |
| `GET` | `/api/roster` | 学生的静态人设（页面一打开就能把学生摆进教室，无需等上课） |
| `POST` | `/api/class/start` | 开一堂课（会话式）：SSE 推 `start` + 第 1 轮，然后保持会话待老师回话 |
| `POST` | `/api/class/reply` | 老师回话，SSE 推下一轮；到最后一轮自动收尾（`done`） |
| `POST` | `/api/teach` | 一次性跑完整堂课，SSE 流式逐步推送事件 |
| `GET` | `/api/world/:name` | 取回已持久化的世界对象（跨重启留存） |
| `POST` | `/api/llm` | 按功能组合的文本 / 视觉调用（`fn` = 翻译 / 深度思考 / 对话 / OCR / `combo`） |
| `POST` | `/api/image` | 文生图（Kolors），返回图片 URL 或 `data:` base64 |
| `POST` | `/api/asr` | 语音识别（multipart 音频 → 文本） |

**协议要点**：课堂用 **SSE（`text/event-stream`）** 流式推送；请求体与每个事件的 `data:` 负载均为 JSON。
**安全护栏**（已落）：`/api/world/:name` 路径名白名单（仅 `[A-Za-z0-9_-]`）防穿越；请求体体积上限；静态文件路径校验。**未落**：鉴权、限流。
