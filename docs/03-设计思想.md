# 03 · 设计思想

> 灵境为什么长成这样：角色契约、盲区照见反思环、理论依据、以及我们主动删掉的东西。

---

## 一、一条角色契约（不可漂移红线）

| 角色 | 职责 | **不做什么** |
|---|---|---|
| **人类（体验者 / 传授者）** | 讲出自己的知识 / 经验 / 技能；回答学生的追问；**逐条自判"答到了没有"** | 不把判定外包给机器 |
| **AI 学生（激发者 / 镜子）** | 抛探测（真实文本）、照出人类讲解里没讲透的口子 | **不学习、不评分、不声称"懂了"、不做"学生→分数"边** |
| **判定者 = 人类本人** | 课后读并排清单，心里"咯噔"处即口子 | 机器不代判 |

**课堂形态**：**一面镜子**（1 名学生 · 小明 · 好奇型，2026-09-18 定案），不是一群分角色的学生 ——
人类要的是一面能照出缝的镜子，角色分工会把注意力从"我的讲解"引到"学生性格"上。

**架构不变量（代码层强制）**：世界 `World = ⟨S, R, M, T⟩` 中**不存在"学生→分数"关系**。

一切"懂没懂 / 答到了没有"的自动判定，灵境一律不做。机器只做两件它真做得到的事：

1. 对人类讲解文本做**确定性弱信号检测**（定位可能漏讲的地方）；
2. 把学生原话与先生原话**逐条并排**（镜子）。

这不是产品克制，是**能力边界**：一个 AI 学生没有脑子，"它懂了没有"没有真值可读。任何声称能读出来的量，读的都是模型采样噪声。

## 二、最深的价值流程：盲区照见反思环

```
人讲(Teach) ──▶ AI 多角追问(Ask/Probe) ──▶ 人答(Respond) ──▶ 人自判(Judge＝人) ──▶ 带走(思考/盲区/总结)
                  ▲                                                          │
                  └──────────── 下一轮：新问题来自上一轮没答透的口子 ────────┘
```

| 环节 | 发生什么 | 谁在做 |
|---|---|---|
| **Teach** | 人类注入任意知识 / 经验 / 技能（引擎不生成其内容） | 人 |
| **Ask / Probe** | 七类探测（反例 / 边界 / 正例 / 区分 / 机制 / 应用 / 落地），学生产出**真实文本** | 确定性定位层 + 提问引擎 + 大模型"嗓音" |
| **Respond** | 人类回话，原文回填到对应探测 | 人 |
| **Judge** | **只发生在人脑**：课后逐条读"他问的 / 你答的"并排清单 | 人 |
| **带走** | 课堂纪要 + 讲授收获 + AI 理解笔记 + 跨课无知地图 | 人带走 |

**深度指标（不评分，只计数 / 看增长）**：单课探测构成 + 跨课个人无知地图增长 + 课后总结（人自己写的）。

## 三、设计公式（不含任何评分项）

```
盲区环深度 D  ∝  Σ(人类真生成的回答)            // 生成效应：人答得越多，环越深
              + Σ(被并排的"他问 / 你答"原文对)   // 镜子：原话越多，自判越准
              − 0 × (任何"学生理解度"量)          // 该量已删，不参与

薄弱点定位 L  = detectWeakPoints(讲解文本)        // 确定性、可复现、跨场景取值不同
探测定向       = argmax_{未消耗薄弱点} severity → (conceptIdx, probeType)
```

第二条式子是整个产品的地基：**"AI 学生从哪个角度问"不靠模型猜人类哪里漏讲**，而靠对讲解文本做可解释、可复现的弱信号检测。见 [04 · 技术参考](04-技术参考.md) 第二节。

## 四、理论依据（为什么这样设计）

> **诚实前置**：下列研究是**设计依据**，不是"我们已达到该效果"的证据。研究引用 ≠ 产品复现。

### 4.1 门徒效应与可教代理（基石）

- **门徒效应（Protégé Effect, Chase et al. 2009）**：当人以为自己在教一个"可教代理"时，投入与效果显著优于"为自己学"；人会社会性看待 AI、产生责任感；**失败发生在 AI 学生身上，不打击传授者自尊**——这是体验安全感的基础。
- **可教代理范式（Betty's Brain / Biswas et al. 2005；ALTER-Math / Xing et al. 2025）**：人类当老师、AI 当学徒，在传授中完成知识重构。ALTER-Math 已服务数万中学生，证明"AI 当学生"可规模落地（其原话大意：「AI 还不是可靠的老师，但 AI 是出色的学生」）。
- **LLM 门生（Kucharavy et al., BEA 2025）**：把 LLM 当"会犯错的学生"来辅导，在算法课中成功诊断其错误的学生成绩显著更好。

### 4.2 认知科学七条 → 盲区环的子机制

| 理论 | 落在盲区环哪里 |
|---|---|
| 认知冲突 / Impasse | 学生职责＝制造 impasse（卡住），不是配合点头；探测即 impasse 引信 |
| 生成效应 | 人"答"这步必须真生成，不能只听 |
| 最近发展区 ZPD | 探测指向"人类刚讲到、但还没讲透"的要点 |
| 认知负荷 | 每轮只抛一枚探测，类型错开，不堆 |
| 自我决定 | 无外部评分才保内在动机 |
| 对话式教学 / 心理操作标签 | 七类探测句式即心理操作标签 |
| 认知学徒制 | "AI 理解笔记"把学生思维外化给人类看 |

### 4.3 第二批：隐性知识 / 心理安全 / 心流 / 社会临场感 / 检索练习 / 知识诅咒

- **隐性知识**：「我们所知的，多于我们所能言说的」。经验、手艺、判断靠定义式提问萃取不出来，必须靠案例 / 边界 / 权衡类提问——这是灵境真正的护城河。
- **外化（隐性 → 显性）**：把脑子里的经验、直觉转化成可描述的显性表达，是最难一步；灵境的核心抓手就是帮人完成这一步。
- **心理安全**：「不被评判」才敢暴露模糊认知——灵境靠"不评分、不纠错、只倾听 + 提问"结构性实现。
- **心流 / 难度校准**：提问难度随人类响应模式动态调（流畅 → 更深；卡住 → 退回澄清）。
- **社会临场感 / 身份拟人**：拟人化提升效果靠激发积极情绪；AI 学生有稳定名字 + 记忆连续性（低人格化，不挡人）。
- **检索练习 / 测试效应**：「传授」本身＝持续检索练习；体验中不给反馈，课后笔记触发自发现。
- **知识诅咒（Camerer 1989）**：专家默认前提、跳背景；AI 学徒持续扮零基础，追问隐含假设。

### 4.4 幻觉 → 优势：我们的反转（含独立判断）

大模型"随机预测下一个词、一定会出错"的弱点，在灵境里不是 bug 而是 feature——AI 学生天然冒出"没跟上 / 理解岔了"的提问，恰好逼人去解释、去补漏，正是门徒效应。

**但（不附和）**：这个反转**只有当随机性被导到真缺口上时才成立**。光靠原生 LLM 自由发挥，随机性会退化成"提问抓不住重点、揪无关细节"。灵境的解法不是消灭随机，而是**用确定性薄弱点定位层把随机性导流**——AI 学生的困惑落在该落的口子上。

> 佐证：让 LLM 像真学徒一样会卡住，本身是活跃研究子领域（engineering fallibility）。Jin et al.（CHI 2024，AlgoBo 的 Reflect-Respond pipeline）用知识态锁死 LLM 上限；Miller & Bosch、Yang et al. 提出约束式 prompt / 工程化知识缺口——共同印证「原生 LLM 太全能反而毁掉学徒角色，须用确定性约束导流」。

## 五、有意不做的事（试过、标定、删掉）

| 事项 | 为什么不做 |
|---|---|
| **自动判定"学生懂没懂"** | 无真值可读。曾实装的知识状态矩阵 / 教学效果 / 差异度，其源头是"模型采样出的学生自评"或"2-gram 文本重叠噪声"，属假理论。2026-09-11 全部移除，**不再计算也不再展示** |
| **自动判定"你答到了没有"** | 同上。机器只数事实（抛了几枚探测、你回了几个、逐条并排原文），结论留给人 |
| **用分数替代人的自判** | 竞品普遍"教完考一下"；灵境的差异化正是"不替代，把判定的咯噔留给人" |
| **学生性格评分 / 好感度系统** | 会诱导情感依赖，也在能力边界外 |
| **把学生做成一个班（多角色分性格）** | 2026-09-18 减为**一面镜子**：角色分工会把注意力从"我的讲解"引到"学生性格"上。代码里保留多生形态的底层，但不启用 |
| **能力/知识矩阵热力图给学生看** | 课堂现场只出现人能一眼懂的东西；一切内部指标收进课后抽屉，默认不展开 |

**一句总结**：这些不是"暂时没做"，是**试过、标定发现是噪声、主动删掉**。

## 六、防漂移红线（改代码前先读这一节）

1. **任何加场景 / 功能，先证「它深化了盲区照见反思环」。** 不铺职业、不堆 3D 特效、不加学生性格评分。
2. **判定权永不泄漏**：不得新增"学生 → 分数"边、不得复活自动判定 / 学生自评。
3. **数学量必真动**：新增任何量（severity / 覆盖率 / 熵），须有测试证明跨场景取值不同；恒为 0 / 恒定值＝摆设，删除。
4. **对外表述诚实**：研究引用 ≠ 产品复现；不声称"知道 AI 学生懂没懂""知道你答到了没有"。
5. **数据不删不对外不评分**：笔记 / 探测 / 无知地图全留世界，课后抽屉默认收起，课堂上永不出现内部指标。

## 七、差异化（vs 同类产品，2026-09 联网核验）

| 竞品 | 范式 | 是否评分 / 判定权归谁 | 与灵境的关系 |
|---|---|---|---|
| **Axiom Flow** | 教 AI 学生 Sam（故意带错）；Sam 考 10 题 MCQ，**分数＝你的成绩** | **评分** | 同范式但反向：它把"教"变成考试 |
| **Chrysalis** | 双模式：AI 导师 + 教 AI 门生；门生模式带 quiz 评估 | **评分** | 同范式但保留评估层 |
| **ALTER-Math** | 初中生教"弱化"AI 解代数；挣积分 | gamification，非对人评分 | K12 数学 + 积分，定位不同 |
| **短视频平台的「费曼 Prompt 玩法」** | 单轮 Prompt 扮演"零基础小白" | 无（但常出戏 / 抓不住重点） | 灵境要解的正是"临时扮演不稳定" |

**头号差异化（对外口径）**：当前"教 AI"范式里，**只有灵境把"只提问、绝不评分"做成架构不变量**（世界无"学生 → 分数"边）。别的产品默认"教完要考一下"，用分数替代人的自判。
