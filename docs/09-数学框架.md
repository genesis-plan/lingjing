## 一、第一性公理（三条不可推导）

#### 公理 A1：人类是外部输入
人类讲解的内容只被注入，不被引擎生成；人类"答到了没有、懂没懂"的判定**不被任何算法计算**。
\[
\boxed{\mathcal{U} = \{ u \in \text{人脑} \mid \text{引擎读不到、算不出} \}}
\]
引擎对 \(\mathcal{U}\) 唯一能做的是：**把人自己的话原样并排给人看**，让人自己判。

#### 公理 A2：镜子不评分
AI 学生只反射、只提问、只累积；不存在从"探测"到"评分"的边。
\[
\boxed{\nexists\ \text{Probe} \to \text{Score}}
\]
任何新增功能，若隐含"AI 判人懂没懂"，即违反本公理，判为漂移。

#### 公理 A3：数据不删不编造
人类留下的盲区、行动、保留困惑，append-only 持久化；不删、不替人补全、不编造。
\[
\boxed{\text{Traj}_{t+1} = \text{Traj}_t \oplus \text{lesson}_t,\quad \oplus\ \text{append-only}}
\]

## 二、状态空间

### 2.1 世界 \(\langle S, R, M, T \rangle\)
产品以"世界"承载持久作品（来自 `world.js`）：
- \(S\)：实体集（lesson / note / kstate / 人定稿）
- \(R\)：关系集，核心为 `teachingRelation`（人 → AI 学生的传授边）
- \(M\)：记忆 / 无知地图（跨课累积的盲区史）
- \(T\)：时间轴

### 2.2 人类知识子空间：用"盲区集合"而非"掌握概率"
我们**不**表示"人对知识点 \(k_j\) 的掌握概率 \(p_{i,j}(t)\)"——那是不可知的真值，曾用 LLM 自评或 2-gram 重叠去近似，属假理论，已停用。
诚实可用的表示是**人自己标出的盲区集合**：
\[
\boxed{\mathcal{B}_t = \{ b \mid b\ \text{是人这课主动留下的"保留困惑/没答透的口子"} \} \subseteq \text{Traj}_t}
\]
\(\mathcal{B}_t\) 不是引擎推断出来的，是人在定稿里写下来的。引擎只负责**累积与回显** \(\mathcal{B}_t\)。

## 三、灵境照见代数（LingJing Illumination Algebra, LJA）

> 从三条公理出发，产品只需四种数学能力：**局部照出本课缺口、跨课累积轨迹、课间搬运概念、长期浮现盲区拓扑**。
> 这四种能力各自都已是成熟数学分支的标准构造；灵境的"特有"在于——把它们**组合成一个守 A1/A2/A3 的、不评分的、只度量机器真做得到的量的闭环**，并一一对应到真实模块。
> 组合本身不声称新定理，是工程化合成（重构而非发明）。

### 3.1 缺口算子 \(\Gamma\) — 信息散度（局域，每课）
把人类讲解文本 \(L\) 当作一个在概念词表上的分布 \(p_L\)，检测"文本内部自相矛盾的缺口"：
- **术语未解释**：某词自信息高（罕见 / 突兀）但在前文零条件支持 → 局部 surprise。
- **逻辑跳步**：相邻句子互信息 \(I(\text{句}_{i};\text{句}_{i+1})\) 低（前提未降低结论的不确定性）→ 跳变。
- **抽象无例**：抽象熵高、具体词比低。
- **复述**：句与前文 KL 近零（信息增益≈0）。
- **前提盲区**：被引用的前置概念在 \(p_L\) 中零覆盖。

聚合为每课的缺口集：
\[
\boxed{\Gamma(L) = \{\,\gamma_i \mid \gamma_i\ \text{是上述五类局域信息散度信号之一，带严重度}\,s_i\,\}}
\]
\[
\text{其中}\quad I(X;Y)=H(X)-H(X\mid Y),\quad D_{\mathrm{KL}}(p\|q)=\sum_x p(x)\log\frac{p(x)}{q(x)}\ge 0
\]
**诚实注**：`jargon`/`jump`/`parrot` 可严格对应信息散度原语（高自信息惊讶 / 低互信息跳变 / 近零信息增益）；`abstract`（抽象熵信号）、`omit`（前提覆盖缺口）属信息论相关启发式但**非严格散度**。五类统一称"信息论相关弱信号启发式"。当前实现用**确定性正则启发式**逼近（不调 LLM、不学权重），等价精神一致。\(\Gamma\) 度量的永远是"文本内部一致性"这一机器可读属性，**绝不度量人**。
映射到：`detectWeakPoints`（正则信号+严重度）、`questioning.js`（按严重度钉探针）、`buildMirrorDraft`（noEval 镜稿）。 **状态：已落**（跨文本严重度必不同，有测试守护）。

### 3.2 轨迹算子 \(\oplus\) — 自由幺半群（跨课累积）
跨课轨迹是事件溯源的**自由幺半群**：以每课 \(L_t\) 为生成元，拼接为序列，空序列为单位元。
\[
\boxed{\text{Traj} = L_1 \oplus L_2 \oplus \cdots \oplus L_n,\quad \oplus=\text{append},\quad \varepsilon=\text{空轨迹}}
\]
自由幺半群的**泛性质**保证：任意对轨迹的聚合（盲区计数、复现次数、复习调度）都是一次 **fold**（沿序列归约），无需额外结构。这正是"先记列表、后按需折叠"的数学根据——轨迹只负责忠实累积，聚合延迟到被照见时。
映射到：`accumulateTrajectory`（reflection.js）+ localStorage append-only。 **状态：已落**。

### 3.3 迁移算子 \(\Phi\) — 最优传输（课间概念搬运）
把两课的概念词袋视为两个分布，课间"概念搬运成本"＝把一课的概念质量搬到另一课所需的最小传输代价（Earth-Mover / Wasserstein 距离的精神）：
\[
\boxed{\Phi(L_a, L_b) = \text{EMD}\big(\text{bag}(L_a),\ \text{bag}(L_b)\big)}
\]
- **Integrate（连到已有）**：取历史课中搬运成本**最低**者 → 最自然可衔接的点（已用词袋余弦近邻近似）。
- **Extend（迁移）**：取历史课中搬运成本**最高**者 → 最陌生的迁移靶，逼人跨域使用（已用最小相似度近似）。
**诚实注**：当前实现用**余弦相似度**作可计算代理（够用则不再升级）；Wasserstein/EMD 是更几何严谨的形式，列为"路线"。两者驱动的逻辑一致：低距离=自然连接、高距离=强迫迁移。⚠️ 升级到 Wasserstein/EMD **非 drop-in**：它需向量嵌入表示，当前 bag-of-words 词袋不足以支撑几何传输；若实装须先引入 embedding（路线）。
映射到：`buildSummaryAssist.summaryIntegrate` / `summaryExtend`。 **状态：已落（余弦代理）**。

### 3.4 拓扑算子 \(\beta\) — 持久同调（盲区拓扑，路线）
把累积盲区视为概念空间中的点云（每点坐标＝该盲区概念词袋）。以相似半径 \(\varepsilon\) 做 Vietoris–Rips 过滤，追踪连通分支（0 维同调 \(\beta_0\)）的"生–灭"：
\[
\boxed{\text{persistence}(\text{簇}) = \varepsilon_{\text{death}} - \varepsilon_{\text{birth}}}
\]
- **长条（高 persistence）**＝稳定、反复出现的主题簇 → 人的**慢性卡点 / 主要矛盾**。
- **短条**＝一次性噪声，不追。
持久同调对噪声稳定（bottleneck 距离 Lipschitz），适合"从稀疏盲区里区分真结构 vs 偶发"。它把"抓主要矛盾"从"数复现次数"升级为"看拓扑持久度"——最大持久簇即主要矛盾。
映射到：未来 `buildMainContradictionPrompt` 的排序依据（当前用原始复现次数 reps，持久同调为更 principled 升级）。 **状态：路线**（当前数据量下余弦/复现计数已够用，待真人信号后再实装）。

## 四、组合演化定律（守 A1/A2/A3）

闭环的演化只有两条边，且**机器无权自主改写盲区**：

\[
\boxed{\text{Traj}_{t+1} = \text{Traj}_t \oplus L_t}
\qquad\text{（机器自动，append-only）}
\]

\[
\boxed{\mathcal{B}_{t+1} = \mathcal{B}_t \cup H(L_t)}
\qquad\text{其中 } H=\text{人标（非引擎推断）}
\]

- 机器侧只有 \(\oplus\)：忠实累积，不改写。
- 盲区 \(\mathcal{B}\) 的**唯一**增量是人自己写下的 \(H(L_t)\)；引擎绝不做"从探测反推人懂没懂"的自主更新——那会违反 A1/A2。
- 巩固算子（人撰总结）是**唯一**能重新结构 \(\mathcal{B}\) 的算子：人把体验收口为可迁移留存时，可合并/重述旧盲区，但主动权在人。

导出量（全部"真会动"，驱动脚手架）：
- \(n_t = |\mathcal{B}_t|\)：累积保留困惑数
- \(m_t = |\text{entries}(\text{Traj}_t)|\)：跨课数
- \(\Gamma\) 严重度谱：本课缺口分布
- \(\Phi\) 近邻 / 迁移靶：跨课概念链接

## 七、一句话总结

**灵境 = 把"人讲 → AI 多角追问（\(\Gamma\) 确定性缺口定位）→ 人答 → 人自判 → 带走盲区/总结"闭环，用"灵境照见代数"形式化：\(\Gamma\) 照出本课缺口、\(\oplus\) 跨课 append-only 累积、\(\Phi\) 课间搬运概念、\(\beta\) 长期浮现盲区拓扑；AI 只当不评分的镜子与脚手架，人类始终是判定者——所有数学只度量机器真做得到、且不替人下结论的量。**

## 八、灵境算法组合框架（扩展层：判定 · 形式化 · 巩固分析）

> 在 LJA 照见层（\(\Gamma\) 缺口 / \(\oplus\) 轨迹 / \(\Phi\) 迁移 / \(\beta\) 拓扑）之上，再吸收六类公开数学构造，扩展出三件事，使"镜子永不评分"在数学上更刚性、盲区更严格、跨课巩固更 principled：
> ① **形式化盲区**：把 \(\mathcal{B}_t\) 严格定义为粗糙集边界区；
> ② **判定层**：给每候选盲区三态判定（接受/拒绝/延迟），镜子唯一合法输出；
> ③ **巩固分析层**：跨课盲区聚类（概念格）+ 盲区形状（覆盖骨架）+ 粒层纪律。
> 同样：组合本身不声称新定理，是工程化合成；凡标"路线"者待真人信号后实装；数学量必须"跨输入必不同"。

### 8.1 边界区算子 \(\partial\) — 把盲区严格化（粗糙集下/上近似）

设不可分辨关系 \(P\)（由概念共现词袋诱导的等价类）作用于论域 \(X\)（本课候选缺口集合），则：
\[
\underline{P}X = \{\,x \mid [x]_P \subseteq X\,\},\quad
\overline{P}X = \{\,x \mid [x]_P \cap X \neq\varnothing\,\},\quad
\partial X = \overline{P}X \setminus \underline{P}X
\]
\(\partial X\)（**边界区**）＝**无法确切判定"是/否盲区"的对象**＝本产品"盲区"的严格定义。粗糙集客观、无需外部参数 / 概率分布 / 隶属度，与"只度量机器读得到的量"高度契合；边界区基数 \(|\partial X|\) 即模糊度度量，可作诚实"无知量"之一。
映射：\(\mathcal{B}_t\)（world.js \(M\) / trajectory）；與 §二 2.2 的盲区集合定义同源。
状态：**已落（盲区即边界区定义）**；下/上近似的显式计算＝**路线**（需先定义不可分辨关系 \(P\)，属轻量但非 MVP 必需）。

### 8.2 三态判定算子 \(\Delta\) — 镜子唯一合法输出（三枝判定）

对每候选盲区给**三态判定**，镜子永不输出分数：
\[
\text{POS}=\text{接受（确为盲区）},\quad \text{NEG}=\text{拒绝（误报）},\quad \text{BND}=\text{延迟（信息不足，继续追问）}
\]
三态由一对接受/拒绝评估函数 + 阈值对 \((\alpha,\beta)\) 把论域三划分；\(\text{BND}\) 区＝"不知道，再问"——正是镜子的本职。人标 \(H(L_t)\) 把候选从 \(\text{BND}\) 推入 \(\text{POS}\)（或 \(\text{NEG}\)）；机器永不自主决定。这把 A2"镜子不评分"落成显式数据结构。
映射：`questioning.js`（探针＝BND 动作）+ `buildMirrorDraft`（noEval 镜稿）。
状态：**部分已落（提问即延迟动作）/ 显式三态结构＝路线**（待把判定存为 \(\text{POS/NEG/BND}\) 三元数据，便宜、高诚实价值）。

### 8.3 证据区间算子 \(m\) — 把"不知道"显式度量（信念-似真区间）

把"不知道"建模为可度量量：识别框架 \(\Theta\)＝候选盲区集，基本信度分配 \(m:2^\Theta\to[0,1]\) 诱导信念/似真函数，区间 \([Bel(A),Pl(A)]\) 包住真概率，gap \(Pl-Bel\)＝**无知度**：
\[
Bel(A)=\sum_{B\subseteq A}m(B),\quad Pl(A)=\sum_{B\cap A\neq\varnothing}m(B)
\]
本产品**只取这套词汇的诚实性**：对任意盲区候选报告 \([Bel,Pl]\) 而非伪概率点估计；**不在 MVP 跑全幂集组合**（\(2^{|\Theta|}\) 爆炸，收益不抵算力，YAGNI）。
映射：作为 \(\Gamma\) 严重度的"区间化"表述（替代单值严重度，避免伪装成概率）——**路线（vocabulary）**；全组合＝**不做**。

### 8.4 概念格算子 \(\Lambda\) — 跨课巩固分析（形式概念分析）

形式背景 \((G,M,I)\)：对象 \(G\)＝各课 \(L_t\)，属性 \(M\)＝弱信号类型（jargon/jump/abstract/parrot/omit），\(I\)＝"该课是否触发该信号"。导出算子出**概念格**，节点＝(extent 共享信号的课集, intent 共享课的信号集)；格序＝特化/泛化。用于跨课**巩固分析**：同信号聚成的概念＝慢性卡点类型，喂给 \(\beta\)（拓扑）与 \(\Delta\)（判定）。确定性、不评分；但全格随对象数指数膨胀，作**离线分析透镜**而非运行时。
状态：**路线（分析透镜）**。

### 8.5 覆盖骨架算子 \(\Sigma\) — 盲区形状可视化（覆盖-Nerve / TDA）

## 九、方法层（建模 · 图论 · 归纳 · 优化 · 序贯 · 动力）

> 在"算子层"之上，再补六类**工程方法**——它们不是新算子，而是把既有能力落到"可证明 / 可优化 / 可迭代"的纪律。每条都过"工程能落地"筛子：要么已落、要么路线（待真人信号/轻量依赖）、要么 YAGNI。

### 9.1 图论算子 \(\mathcal{G}\) — 概念/课图（中心性 + 社区）

盲区/概念作节点 \(V\)，共现（同一课触发的信号）与传授边（teachingRelation）作边 \(E\)，权重＝共现次数 → 图 \(\mathcal{G}=(V,E,w)\)。
- **中心性**：度中心性 \(c_D(v)=\deg(v)\)、介数（最短路径桥）、PageRank（权威传播）→ 找"主要矛盾"节点，是 \(\beta\) 复现计数 reps 的**更 principled 升级**（持久度→图中心度）。
- **社区**：连通分量（\(O(|V|+|E|)\)，免费）、模块度/Louvain（需共现矩阵）→ 盲区聚类，与 \(\Lambda\) 概念格、\(\Sigma\) 骨架互补。
- **最短路**：Integrate 的图版——最自然衔接点＝最短路径邻。
映射：新模块 `graph.js`（或扩 `reflection.js`）。
状态：**路线（P2，便宜高值）**——连通分量 + 度中心性即可落地；PageRank/模块度待共现矩阵，小型图算力忽略不计。

### 9.2 结构归纳 \(\mathbb{I}\) — 轨迹正确性的证明纪律

\(\oplus\) 自由幺半群上，所有聚合＝fold＝来自初始代数的**唯一同态 catamorphism**；结构归纳给出可证的一致性强基：
\[
[ P(\varepsilon) ] \land [ \forall L_t.\ P(\text{Traj}_t) \Rightarrow P(\text{Traj}_t \oplus L_t) ] \implies \forall \text{Traj}.\, P(\text{Traj})
\]
基例 \(\varepsilon\)（空轨迹）、归纳步 append——证明"机器只 append-only、所有派生量皆 fold、永不自主改写盲区"在结构上恒成立。非运行时特征，是**验证纪律**（坐实 §3.2 的 fold 泛性质）。
状态：**已落（证明纪律）**。

### 9.3 数学建模纪律 \(MB\) — 把每个功能框成形式模型

建模循环（迭代）：定问题 → 假设简化 → 形式化 → 分析 → 验证 → 解释 → refine。本品应用：
- 复习调度 = **离散动力系统**（见 9.6）；
- 巩固选择 = **子模优化**（见 9.4）；
- 整闭环 = **状态机 / 事件溯源**（\(\oplus\) 轨迹即事件日志）。
状态：**已落（贯穿框架的建模纪律）**。

### 9.4 子模优化 \(SUB\) — 选择即"边际增益递减"

挑重点/连已有/可迁移等选择任务，建模为单调子模函数最大化 \(f:\mathcal{V}\to\mathbb{R}\)：
\[
f(A\cup\{i\})-f(A) \ge f(B\cup\{i\})-f(B),\quad A\subseteq B
\]
贪心保证 \(\ge (1-1/e)\approx 0.63\) 最优。映射：`buildSummaryAssist.summarySelect`（子模贪心 × 多样性）。
状态：**已落**（已用，此处显式其数学名与保证）。

### 9.5 序贯三枝 \(\Delta^\ast\) — 持续追问直到三划分（序贯检验）

把 \(\Delta\) 三态判定升级为**序贯**：每收一次人回答，更新证据对数比 \(\Lambda_n\)，\(\Lambda_n\le A\)→接受(\(\text{POS}\))、\(\Lambda_n\ge B\)→拒绝(\(\text{NEG}\))、否则继续追问(\(\text{BND}\))。正是不评分镜子的提问循环——**不问够不强行判定**，守 A2。
映射：`questioning.js` 探针循环（当前已隐式"问了再问"，补为显式序贯判定）。
状态：**路线（P2，便宜）**。

### 9.6 动力建模 \(DS\) — 复习即离散动力系统

留存随时间指数衰减、每次复习重置并增大稳定性：
\[
R(t)=e^{-t/S},\quad \text{复习后 } R\leftarrow 1,\ S\leftarrow S\cdot(1+\text{quality})\ ;\quad \text{SM-2 间隔}_{n}=\text{间隔}_{n-1}\times EF
\]
映射：`buildReviewSchedulePrompts`（SM-2）。状态：**已落**（SM-2 已落；FSRS 式双参数拟合标路线，当前不需）。

## 十、领域融合层（心理学 · UX · 知识管理 · 机制设计）→ 体验锚点

> 前九节是"机器真做得到的数学"（算子层 + 扩展判定/形式化层 + 方法层）。本节把**人类体验**作为第一性约束，吸收心理学 / UX / 知识管理 / 机制设计的硬实据，翻译成灵境镜环的体验设计原则。
> 红线纪律：所有跨域理论**只作"为什么这样做"的根据**，不进交付物口径；来源（提出者/文献）仅记私有 daily memory 供连续性。凡与"不评分 / 不做情感依赖"红线冲突处（典型即 SDT 的 relatedness），显式给出**安全落法**。全部原则守 A1/A2/A3。

### 10.1 心理学锚点

#### 10.1.1 ZPD（最近发展区）↔ 探针难度落于 ZPD 通道
- **原意**：实际发展水平（独立解决）↔ 潜在发展水平（成人/更有能力同伴协作下可达到）之间为 ZPD；低于 ZPD＝已掌握（无成长）、高于 ZPD＝挫折区（导致放弃）。脚手架（scaffolding）随能力增长渐退（fading）。
- **灵境落法**：`questioning.js` 六层递进 + 响应模式校准＝把探针难度锚定在人的 ZPD 通道——`stuck` 降档（退到更具体）、`fluent` 升档（更抽象/迁移），避免落入挫折区；镜子的"多角追问→人主导复述/定稿"＝脚手架 fading。
- **体验价值**：人始终"跳一跳够得着"，不无聊、不挫败。

#### 10.1.2 SDT（自我决定理论）↔ 三条需要＝镜环动机底座
- **autonomy（自主）**：人定稿、人判、镜子不替人决定 → A2/A1 的动机学根据；移除一切外部控制（评分/奖励/指令）支持内在动机。
- **competence（胜任）**：镜子提供"成长可见性"（盲区轨迹 \(n_t\) 消长、复习到期被完成）——不评分却让人感到"我能"。
- **relatedness（关系）⚠️ 红线敏感**：灵境**不做情感依赖**、AI 不当陪伴。relatedness 的诚实落法＝①人与自己的思考建立关系（外部"思考伙伴"，Zettelkasten 精神，见 10.2）；②课室作为探询空间（非孤独）。**绝不**把 relatedness 实现为"AI 拟人陪伴/情感联结"——那违反《人工智能拟人化互动服务管理暂行办法》合规红线。
- **过度理由效应（overjustification）**：外部奖励（评分/等级/物质）会削弱内在动机 → 灵境"不评分/不奖励/不排名"是动机学上的机制设计，不只是红线（与 10.3 机制设计互证）。

#### 10.1.3 testing effect / desirable difficulties（Bjork）↔ 镜子逼人生成而非接收
- **原意**：检索练习 > 重读；合意困难（生成/预测试/间隔/交错）增强长期留存。证据 Karpicke & Roediger (2008)：测试 vs 重学，一周后召回 ≈80% vs 33%。
- **灵境落法**：镜子本职是逼人**生成/检索**（解释、辩护、举例、"反过来呢"），而非给答案让人重读；"合意困难"＝镜子制造 productive confusion（aporia）而非填坑。等待（silence）机制＝让人多待一会检索，正合 desirable difficulty。

#### 10.1.4 Socratic / maieutics（苏格拉底产婆术）↔ "AI 学生只是镜子"的哲学锚点
- **原意**：elenchus（揭露矛盾）+ aporia（建设性困惑）+ maieutics（助产 latent 理解）；提问者非权威、不直给答案。
- **灵境落法**：`questioning.js` 六类探测＝苏格拉底式提问框架（澄清/假设/证据/视角/后果/追问问题本身），全"学徒姿态"非"教师姿态"。坐实 A2"不评分"——镜子是 midwife 不是 judge。

#### 10.1.5 元认知 Flavell + 元理解错觉（illusions of competence）↔ 镜子存在的根本理由
- **原意**：元认知三成分（知识/体验/调节）；监测常不准（元理解错觉）→ 人常"以为懂了其实没懂"。
- **灵境落法**：镜子提供**外部元认知反馈**（把人原话并排、写"我没跟上/可能理解偏"）纠正元理解错觉；但**不评分**——评分反强化错觉+外在动机。EEF 估元认知+自调 ≈ +8 月进步。

#### 10.1.6 认知负荷 Sweller ↔ 界面零噪音
- **原意**：内在/外来/相关三型；工作记忆 ≈4 chunk（Cowan）。外来负荷应消除、相关负荷促 schema。
- **灵境落法**：体验层**不泄漏任何内部指标**（R̄/σ²/轮次/完整度/落盘路径/LLM 状态）——消除外来负荷；镜子让人建构 schema（相关负荷）。split-attention / worked-example / expertise reversal → 对新手多脚手架、对专家少帮（fading）。

#### 10.1.7 flow（Csikszentmihalyi 心流）↔ 体验通道设计
- **原意**：挑战-技能平衡（略高于当前 ≈4% 触发流通道）、明确目标、即时反馈、专注无干扰；流脆弱（任何打断碎流）。
- **灵境落法**：镜子反馈即时、界面零打断、挑战略高于当前（同 ZPD）；与"体验层不出现内部指标"红线同源——指标泄漏/弹窗/通知＝碎流。

#### 10.1.8 认知学徒（cognitive apprenticeship）↔ 脚手架→责任转移
- **原意**：建模→脚手架→淡出→责任转移→迁移。
- **灵境落法**：镜子＝脚手架，渐退把责任转移给人（人定稿/人判），与 ZPD fading 同源。

### 10.2 知识管理锚点（Zettelkasten / PKM / 扩展心智）
- **原意**：原子（一卡一念）、用自己的话重写（语义深度加工）、链接而非归档、涌现结构、无预设层级；Luhmann 称 slip-box 为"沟通伙伴（communication partner）"。
- **灵境落法**：课后产物（照镜札记/盲区）＝人的外部"思考伙伴"——原子、自述、可链接留存；跨课轨迹 ⊕ 即"顺链接发现意料外连接"的 slip-box 精神。与"扩展心智"呼应：知识外置到本地轨迹，镜子是外置思考的**界面**而非情感对象（守 10.1.2 relatedness 红线）。

### 10.3 机制设计锚点（博弈论 / 契约理论）
- **原意**：人与 AI 镜子的互动是一个**机制**——规则设计使理性参与者追求自身利益也产出理想个体结果。
- **灵境机制**：移除一切外部激励（无评分/奖励/排名/无 AI 陪伴作奖赏）→ 人无可优化外在指标 → 只剩"对自己诚实"这一自利且内在的方向。这是对 SDT autonomy 与 overjustification 的机制化落地。
- **契约理论（Whang 1992 software contracting）**：信息不对称下用契约对齐激励。灵境"人判契约"（见 `classroom-framework.md`）正是此对齐——判定权在人、机器不越界，避免机器 Opportunism（假评分/假懂）。
- 不引入智能合约/链上（overkill）；只借"机制设计"思维锚定"为什么不评分/不奖励"的底层逻辑。

### 10.4 数学补漏（可落地的形式锚）
- **范畴论 lens / 双向一致性**：渲染状态 ↔ 引擎状态 构成 **lawful lens**——Get（引擎状态→渲染，只读投射）与 Put（人操作→受控回写）满足 GetPut/PutGet 律。给"渲染安全边界"（P0）一个形式化论证：渲染是引擎状态的只读 lawful lens；人类动作经受控 Put 回写（append-only），与 A3 一致。属概念层，不强求实装图表论。
- **信息几何**：盲区/信念状态＝统计流形上的点；Γ 缺口＝该点处 Fisher 信息方向的散度、Φ 迁移＝流形上测地线。概念层，YAGNI（需嵌入）。
- **随机过程 / 贝叶斯**：盲区演化＝信念贝叶斯更新序列（先验→人标→后验），与 D-S（\(m\)）区间一致；SM-2 已是离散动力系统（DS，§九）。
- **控制理论**：镜环＝负反馈控制环（人输出→镜子反射→人调节→再输出），与 flow 即时反馈、元认知监控同源；闭环稳定靠"人判"作为唯一设定点。
- 注：以上数学补漏均**概念层**，落入"路线/YAGNI"，不强加算力；lens 律可借为 P0 渲染安全边界的论证。

### 10.5 领域融合层 → 体验设计原则（人类体验优先·写码前验收口径）
1. **ZPD 通道**：探针难度始终"跳一跳够得着"；stuck 降档、fluent 升档；不进挫折区。
2. **内在动机不劫持**：不评分、不奖励、不排名、不把 AI 扮陪伴；判定与定稿权永远在人。
3. **逼生成不喂答案**：镜子只问不填；等待让人检索；aporia 建设性困惑。
4. **零噪音流通道**：体验层零内部指标泄漏、零打断、即时反馈、清晰目标。
5. **外置思考伙伴**：课后产物原子/自述/可链接；跨课轨迹即第二大脑；镜子是界面不是情感对象。
