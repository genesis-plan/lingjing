# 灵境 LingJing · 方法论基座（MVP 锁定：盲区照见反思环）

> 本文档是产品"盲区照见反思环"的**方法论展开与证据基座**。
> 定位一句话：**人类是体验者（也是传授者），AI 是激发者（不学习、不评分、不判定），判定权永远归人。**
> 最深的价值流程不是"铺功能"，而是**盲区照见反思环**：人讲 → AI 多角追问 → 人答 → 人自判 → 带走思考 / 盲区 / 总结。
>
> 凡涉及"学生懂了多少""你答到了没有"的自动判定，本产品一律不做。
> 本基座只做两件机器真做得到的事：**① 对人类讲解文本做确定性弱信号检测（定位可能漏讲的地方）；② 把学生原话与先生原话逐条并排（镜子）。**

> ⚠️ **文档状态（归档说明）**：本文是**设计期的完整方法论基座**，保留原貌以作方法来源的可追溯记录。
> 两处已随产品演进变化：① 探测类型由「六类」扩为**七类**（2026-09-18 新增「落地」）；② 课堂由多名学生收为**一面镜子**（1 名 · 小明）。
> **实现细节以代码与 [04 · 技术参考](04-技术参考.md) 为准。**

## 一、角色契约（不可漂移红线）

| 角色 | 在世界中的位置 | 职责 | 不做什么 |
|---|---|---|---|
| **人类（体验者 / 传授者）** | 外部输入，内容只注入不生成 | 讲出自己的知识 / 经验 / 技能；回答学生的追问；逐条自判"答到了没有" | 不把判定外包给机器 |
| **AI 学生（激发者 / 镜子）** | 人→AI 学生的传授边；产出笔记作品 | 抛探测（真实文本）、照出人类讲解里没讲透的口子 | 不学习、不评分、不声称"懂了"、不做"探测→评分"边 |
| **判定者 = 人类本人** | 不在世界内（无"探测→评分"边） | 课后读并排清单，心里"咯噔"处即口子 | 机器不代判 |

**不变量（代码层强制）：** 世界无"探测→评分"关系；曾用"文本重叠自动判定"的函数已停用且无调用点；"答到了几枚"在数据模型里不存在，只存在于人读完清单后的脑子里。任一加场景 / 功能，先证"它深化了盲区环"，否则判为漂移。

## 二、最深价值流程：盲区照见反思环

### 2.1 机制命名（与产品代码一一对应）

```
人讲(Teach) ──▶ AI 多角追问(Ask/Probe) ──▶ 人答(Respond) ──▶ 人自判(Judge=人) ──▶ 带走(思考/盲区/总结)
                  ▲                                                          │
                  └──────────── 下一轮：新问题来自上一轮没答透的口子 ────────┘
```

- **Teach**：人类任意知识 / 经验 / 技能，作品持久留世界。
- **Ask / Probe**：六类探测（反例 / 边界 / 正例 / 区分 / 机制 / 应用），由学生产出真实文本。
- **Respond**：人类回话，原文回填到对应探测。
- **Judge**：只发生在人脑，课后逐条读并排清单。
- **带走**：课堂纪要 + 我的收获 + AI 理解笔记 + 跨课无知地图。

### 2.2 体验循环 spec

| 步 | 人类动作 | AI 学生动作（镜子） | 产出 |
|---|---|---|---|
| 1 选主题 | 选自己要厘清的一件事 | — | 课题 |
| 2 传授 | 讲出自己的理解（含可能错的） | 带着旧想法进课堂 | 传授作品 |
| 3 困惑 | — | 抛探测暴露人类没讲透的口子（确定性薄弱点定位） | 探测集 |
| 4 追问 | 回话 | 接话 + 再追问 | 探测回答 |
| 5 重解释 | 把口子讲圆 | 记录先生原话 | 并排清单 |
| 6 展示理解(含错) | — | 写"理解笔记"（可能理解错） | 笔记 |
| 7 人自现缺口 | 读笔记与清单，自判 | — | 思考 / 盲区 / 总结 |
| 8 人判定 | 标出哪几条没答到 | — | 下一课目标 |

**深度指标（不评分，只计数 / 看增长）：** 单课顿悟数（峰检测，仅标记不制造）+ 课后盲区总结准度（人自判）+ 跨课个人无知地图增长（持久）。

## 三、确定性薄弱点定位层（P0-1 工程铁律）

### 3.1 为什么必须"确定性"
盲区环里"AI 从哪角度问"若交给自由发挥，会退化成"不管我输入什么他们都回那几句"。因此薄弱点定位不靠模型猜人类哪里漏讲，而靠对人类讲解文本做**可解释、可复现**的弱信号检测：钉出"可能讲漏 / 讲偏"的位置 → 喂给探针调度 → 哪枚探测去逼哪个口子，有依据。

### 3.2 五类理解漏洞信号（确定性正则，跨场景取值必不同）

| 信号 | 检测（人类文本） | 含义 | 严重度 |
|---|---|---|---|
| `jargon` 用术语未解释 | 出现专业词但同句邻句无解释标记（因为 / 比如 / 即 / 换句话说） | 人类可能"甩术语"，听众接不住 | 2 |
| `jump` 逻辑跳跃 A→C | 出现推理词（所以 / 因此 / 推出 / 意味着）但前一句无前提标记 | 缺了中间的 B，听众跳不过去 | 3（最大盲区） |
| `abstract` 具体→抽象 | 出现抽象词（本质 / 规律 / 核心 / 维度 / 结构 / 框架）但本句无生活例 / 数字锚点 | 从例子突然飞到概念，听众悬空 | 1 |
| `parrot` 用原话非自己话 | 连续两句高度重复（疑似背定义） | 人类没用自己的理解讲，只是复述 | 1 |
| `omit` 前提盲区 | 定论式断言却无启用条件 / 隐含前提 | 人默认的前提没说出口（最深的盲区机制） | 3 |

### 3.3 七类提问策略库 → 六类探测映射（确定性）

| 策略 | 暴露盲区最锋利处 | 映射到探测类型 |
|---|---|---|
| 概念澄清 clarify | 术语到底指什么 | `example`（拿生活例验证） |
| 举例验证 example | 这说法在我生活里算不算 | `example` |
| 因果追问 cause | 中间到底发生了什么 | `mechanism` |
| 假设检验 assume | 什么情况下它就不成立 | `counter` |
| 反例挑战 counter | 反过来成立吗 | `counter` |
| 换位思考 perspective | 换成别的会怎样 | `apply` |
| 元认知 meta | 我自己到底懂没懂 | `apply` |

**调度规则（确定性）：** 每轮给某学生分配探针时，优先取"严重度最高且本轮未消耗"的薄弱点 → 其概念索引定为该学生盯的要点、信号→策略映射定为探测类型；无未消耗薄弱点时退回轮转，保证概念覆盖。效果：人类文本里"用术语没解释"的要点，会被学生用"举个生活例验证"逼；"逻辑跳步"的要点，会被"中间怎么发生的"逼。问题落在该落的口子上。

### 3.4 防数学摆设
`detectWeakPoints` 输出的严重度 / 信号必须**跨不同讲解文本取不同值**（否则是摆设）。验证：用 3 段不同文本（术语密集 / 跳步多 / 平实）断言信号计数与类型不全相同。

## 四、思维可见化笔记：AI 理解笔记（P0-2，镜子机制）

### 4.1 机制
镜子该做的，是把它"学到的"（=人类教的）暴露回给人类，含它可能理解错的地方——人类读到"它理解岔了"，才照见自己哪句讲歧义了。

本产品不声称 AI 有理解，所以笔记是**确定性镜子**，全用真实文本拼装：

```
对每个学生：
  旧想法            ← 进课堂前的误解（已知）
  记下的(先生原话)  ← 它抛的探测收到的回答原文（逐条）
  还没搞清的        ← 它抛了但没收到的回答 / 它探测里还在问的（=人类没讲到的口子）
  一句自我点检      ← 确定性模板："我原来以为 X；先生讲完，我最想不通的是 Y"
```

"含错"天然落在两处：**没收到的回答**（它没得到澄清）+ **它的旧想法**（它带着的错）——这两处正把人类的盲区镜像回给人。

### 4.2 诚实约束
- 数据不删、不对外、不评分。
- 不写"它理解度 37%"这类编的话；只呈原话 + 它自己的旧想法 + 它没搞清的。
- 若要 LLM 生成"学生口吻的理解笔记"，必须标"这是 AI 学生写的、含它可能理解错的，由你来判断"，且不计入任何量。

## 五、差异化卖点（与"别人单会话笔记"的区别）

| 维度 | 别人（单会话 AI 笔记 / 辅导） | 灵境 |
|---|---|---|
| 无知地图 | 课后一份总结，下次重来 | 世界持久无知地图：跨课累积"你常漏的口子" + 复习时刻 |
| 判定权 | 常暗含"AI 判你懂没懂" | 判定权永不泄漏给人（无"探测→评分"边） |
| AI 角色 | 常扮"老师 / 陪练"暗含评分 | 只做激发者 / 镜子，不学习不评分 |
| 最深流程 | 铺功能（题库 / 职业 / 3D） | 只做深盲区照见反思环 |

## 六、设计公式（MVP 阶段，不含任何评分）

```
盲区环深度 D  ∝  Σ(人类真生成的回答)            // 人答得越多，环越深
              + Σ(被并排的"他问/你答"原文对)     // 镜子：原话越多，自判越准
              − 0 × (任何"学生理解度"量)          // 该量已删，不参与

薄弱点定位 L  = detectWeakPoints(讲解文本)        // 确定性，可复现，跨场景取值不同
探测定向       = argmax_{未消耗薄弱点} severity → (conceptIdx, probeType)
```

## 七、防漂移红线

1. **任何加场景 / 功能，先证"它深化了盲区照见反思环"。** 不铺职业、不堆 3D、不加学生性格评分。
2. **判定权永不泄漏**：不得新增"探测→评分"边、不得复活自动判定 / 学生自评。
3. **数学量必真动**：新增任何量（severity / 覆盖率 / 熵），须有测试证明跨场景取值不同；恒为 0 / 恒定值 = 摆设，删除。
4. **对外表述诚实**：研究引用 ≠ 产品复现；不声称"知道 AI 学生懂没懂""知道你答到了没有"。
5. **数据不删不对外不评分**：笔记 / 探测 / 无知地图全留世界，课后抽屉默认收起，课堂上永不出现内部指标。

## 八、提问方法（确定性可执行的薄引擎）

把"灵境怎么提问"收敛成一套**确定性可执行的提问方法**，解耦为独立模块 `questioning.js`：只产出 spec（钉谁 / 什么类型 / 引哪句原话 / 第几层 / 等多久 / 什么姿态），LLM 只是嗓音。

六条确定性规则：
1. **镜面锚定（100% 引用原话）**：截取人类刚说的片段，spec 强制引用原话以问题反弹。
2. **学徒姿态（谦逊探询）**：困惑/好奇库，零评判零纠错零空泛赞美。
3. **六层递进**：澄清→举例→因果→假设→反例→元认知；探测类型→基础层确定性映射，按响应模式升降档（最近发展区脚手架）。
4. **响应模式校准（确定性启发式）**：按人类回答长度分 stuck/partial/fluent；fluent 升档、stuck 降档。
5. **等待/沉默**：等待前缀"让我想想…" + 答完不立即甩下一问、复述确认再推进。
6. **双轨模板（A 显性 / B 隐性）**：A 轨逻辑链 + B 轨场景·权衡链；B 轨检测待接线，当前恒为 A，如实标注不夸大。

验证：`tools/test_questioning.mjs` 断言全过；同输入确定性一致、引用原话确为人类子串、姿态零评分语、六层在界且校准不越界、双轨模板齐全、响应模式三档确定性。

## 九、认知照见引擎（信息间隙制造）

把认知机制收敛成一句话机制——灵境不"教"也不"考"，它在一个心理安全容器里，用确定性薄弱点定位把传授者自己刚说完的话反弹回去（镜面锚定），刻意在他以为讲完的地方制造一个"信息间隙"——而这个间隙恰好落在他的盲区上，触发把隐性知识外显；此时让他多待一会（等待）而非立刻填坑；全程 AI 只当学徒、绝不评判。那一下"哦我原来这里没讲清"的咯噔，就是信息间隙被照见。

该引擎是**工程化组合创新**：每条零件都有可查证的认知研究支撑，但"把它们串成一个可工程实现、且守不评分红线的体验引擎"是本产品的独有组合。对外若称"原创理论"会被戳穿；称"基于既有认知研究、由灵境首次工程化为可运行提问引擎"，站得住。

落到代码的 concretization：
- `omit`（前提盲区）信号已加进 `detectWeakPoints`，严重度=3，映射 → `bound` 探针。
- 对应问句模板已加进 `questioning.js` 的 `TRACK_A.omit`：「你刚说「{q}」——我有点跟不上：这句话在什么样的情况下会站不住？有没有什么是你默默算进去、但没说出来的前提？」以学徒好奇问，绝不摆质疑姿态。
- 模板已注入 hint，LLM 不再自由发挥"怎么问"。

## 十、双稿制（AI 初稿 + 人类终稿）【定稿，不可改动】

> 本节约等于产品白皮书终极规则，一次性锁死，产品完全按此执行。

### 核心范式：AI 初稿 + 人类终审定稿
把"镜鉴"与"判定"分开：
- **AI 写初稿**：呈现"我听到了什么、我哪里没跟上、我可能理解偏了"——这是镜子的反射。
- **人修改终稿**：决定"这些理解对不对、我哪里没讲清楚、下次怎么讲"——这是照镜后的判定。
最终有用的总结，一定是人改过的那一版；AI 初稿只是让人有东西可改。

### 1. AI 初稿写什么（全部用"我"开头，不评价、不建议、不评分）
1. 我听到的核心内容（可含错误理解）
2. 我还没完全明白的地方（以"我没跟上"列困惑）
3. 我可能理解偏了的地方（标注自己不确定的理解）

### 2. 人怎么修改（修改动作本身就是判定权的行使）
| 修改动作 | 含义 | 示例 |
|:---|:---|:---|
| 确认 | AI 理解对了，保留 | 「这条没问题。」 |
| 改写 | AI 理解偏了，改成自己的表述 | AI 写「你说递归就是叫自己」，人改成「递归是函数调用自己，不是'叫自己'。」 |
| 补充 | AI 没听到，但人想补上 | 「这里我还想加一句：终止条件是写代码的人自己定的。」 |
| 删除 | AI 理解完全偏离，删掉 | 「这条不是我的意思，删了。」 |
| 转化 | 把 AI 的困惑变成自己的反思 | AI 写「我不确定终止条件怎么设定」，人改成「我忘了讲终止条件是谁定的，下次要补。」 |

人改完后的文本才是最终总结。AI 初稿不保留为"正确答案"，只作为修改痕迹存在。

### 3. 终稿长什么样（以"递归"为例）
- **AI 初稿**：我听到的是：递归就是函数调用自己。它必须有终止条件，否则会一直调用，最后栈溢出。我还听到递归和栈有关系，但没完全跟上。/ 我没明白：终止条件是谁定的？栈溢出是什么画面？/ 我可能理解偏了：我把递归理解成「函数叫一次自己」。
- **人修改后的终稿**：我讲的核心是：递归是函数调用自己，必须有终止条件，否则栈溢出。递归和栈的关系是每次调用都会往栈里压一帧。/ 我意识到：我忘了讲终止条件是写代码的人自己设定的，AI 在这里卡住了。/ 下次改进：讲递归时，先讲栈，再讲递归，最后讲终止条件。用一个具体的代码例子贯穿。
- 这份终稿完全属于人。AI 没有说"你这里没讲好"，但人自己看到了。

### 4. 为什么这套机制成立（机制闭环）
| 原理 | 在双稿制中的体现 |
|:---|:---|
| 生成效应 | 人修改时主动生成判断和改写，比只读 AI 总结记忆更深 |
| 门徒效应 | AI 初稿是"学生交作业"，人修改是"老师批作业"，责任在人 |
| 心理安全 | AI 初稿不含评价，人不会感到被审判 |
| 判定权归人 | 终稿由人写，AI 不评分、不建议 |
| 锚定效应规避 | AI 初稿只写"我听到的"，不写"你讲得如何"，不给人评价锚点 |
| 反思性实践 | 修改动作本身就是对行动的反思，终稿是可回看的反思轨迹 |

### 5. 产品固定流程（最终版）
1. 用户完成一轮传授对话
2. AI 输出【学徒草稿总结】（标注：草稿·AI 学徒理解·待你修订）
3. 用户对草稿进行：改错、补漏、精炼、补充隐性思考、修正边界
4. 用户点击「定稿」
5. 系统保存【人类终审版最终知识笔记】（唯一沉淀资产）

### 6. 一句话锁死
**AI 写初稿，是为了让人有东西可改；人改终稿，是为了让总结真正属于人。AI 负责让理解可见，人负责让可见的理解变得有意义。判定权不在 AI 不评分，而在人主动改写。**

### 方法命名与细化：双稿三阶镜鉴法
- **命名**：双稿（AI 镜稿 + 人定稿）· 三阶（事实阶 → 反思阶 → 行动阶）· 镜鉴（AI 如镜只反射，人如照镜者做判定）。
- **人定稿三阶模板**（终稿归人，称「照镜札记」）：
  - 一、事实：我讲了什么 / AI 听到了什么
  - 二、反思：哪里顺 / 哪里卡 / 为什么
  - 三、行动：如果重讲一次，我会改变什么
  - 四、保留：暂时无解的问题
- **操作流程七步**：① AI 生成镜稿 → ② 人通读 → ③ 人用五类动作修改（确认/改写/补充/删除/转化）→ ④ 人按三阶写定稿 → ⑤ AI 朗读定稿（可选，只复述不加评价）→ ⑥ 人确认定稿（存「照镜札记」）→ ⑦ 下次传授前回看（可积累认知轨迹）。
- **新增原则**：允许保留困惑（有些问题暂时无解，保留作种子）；总结是下一次的起点，非终点。

> **代码对齐（已实施）：** 已落地 `public/reflection.js`（双模：Node require + 浏览器 window.LJReflection），纯函数载镜稿三块 / 五类修改 reducer / 三阶定稿 / 七步状态；`teacher.js` 生成 mirrorDraft、`summary.mjs` 复用、`classroom.html` 只渲染与采集。总结模块解耦为薄确定性引擎 `reflection.js`，镜像 `questioning.js`。

## 十一、巩固层方法：双稿三阶·镜鉴复盘法（LJ-GMR）

> 对外诚实口径：双稿制 + LJ-GMR 是工程化组合（把既有反思 / 复盘方法落成可单测的确定性脚手架），非理论原创。

### 六类方法 → 原理提取 → 落到引擎
| 方法来源类别 | 提取的原理 | 落地的引擎能力 |
|---|---|---|
| 反思性实践 | 反思是可教的技能，靠结构化提示培养；分行动中/后反思；跨课回看使反思累积 | 七步末步「回看」+ 跨课轨迹 |
| 引导式笔记 | 外部化书写让反思具体；引导提问逼出诚实；小事日积成认知资产 | 引导式设问生成器 + 轨迹累积 |
| 元认知与自我评估 | 监测（知/不知自检）+ 调节（改策略）；自驱非他判 | 元认知自检锚点（盲区/根因/下一步/迁移） |
| 形成性评价与反馈 | 为学而评（形成性）非评判（终结性）；描述性、前瞻、改后续行动才有用 | AI 镜稿恒为形成性（noEval 黑名单铁律）；强调人"行动"阶 |
| AI 辅助反思 | AI 只当镜子照出人认知、助人在机器思维时代守住人性；警惕认知异化（依赖削弱自思） | 已锁死"只照镜不审判"；镜稿全「我」开头、零评价语 |
| 复盘方法 | 回顾目标/评估结果/分析原因/总结规律；复盘≠总结（推演）；三角色（引导人/设问人/叙述人） | 复盘四步锚点；AI 充设问人/引导人，人叙述人 |

### 创造的方法：双稿三阶·镜鉴复盘法（LJ-GMR）
- **锁死核心（不变）**：双稿（AI 初稿 + 人终稿，定稿不可改）、三阶（事实/反思/行动/保留）、五类修改（确认/改写/补充/删除/转化）、七步流程。
- **增强层（纯函数、可单测）**：
  1. **引导式设问** `buildGuidedPrompts(mirrorDraft)`：逐条镜稿出可操作问句，只提问不评判，过 noEval。
  2. **元认知自检** `buildMetacogPrompts()`：盲区/根因/下一步/迁移 四锚点。
  3. **复盘四步** `buildReviewPrompts()`：目标/结果/原因/规律 四锚点。
  4. **跨课轨迹** `accumulateTrajectory(prev, finalDraft)`：保留段=盲区、行动段=意图，逐课累积，数据不删、不替人编造。
  5. **抓主要矛盾** `buildMainContradictionPrompt(prev, fd)`：从累积盲区按频次定位最该先啃的一条。
  6. **自我批评（坚持/修正）** `buildSelfCritiquePrompts()`：人自判"坚持住的(真理)/要修正的(错误)"两锚点。
  7. **渐进试错 / 效果导向** `buildTrialPrompts` / `buildOutcomePrompts()`：先试再定论 / 以成效判懂不拘形式。
  8. **生成式总结** `buildSummaryPrompts(prev, fd)` + 辅助计算 `buildSummaryAssist`：Select/Organize/Integrate/Extend 四锚点，确定性本地启发式给候选/链接/度量。
  9. **跨课复习调度** `buildReviewSchedulePrompts(traj, now)`：SM-2 间隔 + 遗忘曲线，只提示到期不判掌握度。
- **哲学归一句**：AI 只当镜子、只提问、只累积；人叙述、人判定、人定稿。复盘教练 = AI 的非评价角色。

> **代码对齐（已实施）：** `public/reflection.js` 含上述全部纯函数与常量，双模导出；`tools/test_reflection.mjs` 当前 **77 断言全绿**；`public/classroom.html` 课后抽屉渲染全部脚手架，定稿时跨课轨迹前缀自动累积。五套测试（reflection/questioning/weakpoint/p0_wiring/summary）全绿。

## 十三、跨域体验锚点（理论 → 盲区照见反思环）

> 把指令 N 查得的心理学 / UX / 知识管理 / 机制设计硬实据，锚定到盲区环的每一环。凡理论只作"为什么这样做"的根据，提出者/文献来源按"方法诚信"红线**不进交付物**，仅记私有 daily memory。全部守不评分红线；relatedness 处显式避坑。

| 跨域理论 | 锚定到盲区环的哪环 | 在本产品的体现 |
| :--- | :--- | :--- |
| ZPD（最近发展区）/ 认知学徒 | Ask 探针难度 + 责任转移 | 六层递进 + 响应校准（stuck 降/fluent 升）；脚手架 fading→人定稿 |
| SDT（自主/胜任/关系） | 动机底座 | 人判/人定稿（自主）、盲区轨迹消长（胜任）、relatedness 落为"与己思考关系"非 AI 陪伴 |
| testing effect / 合意困难 | Respond/Judge | 镜子逼生成（解释/辩护/举例）、等待让人检索、aporia 建设性困惑 |
| Socratic / maieutics | Ask（镜子姿态） | 六类探测＝苏格拉底式提问（澄清/假设/证据/视角/后果/追问本身），学徒非教师 |
| 元认知 / 元理解错觉 | Judge（外部反馈） | 镜稿并排原话纠正"以为懂了"；不评分（评分反强化错觉） |
| 认知负荷 / flow | Shell 体验层 | 零内部指标泄漏（外来负荷）、零打断即时反馈（流通道） |
| Zettelkasten / 扩展心智 | 带走（跨课） | 照镜札记原子/自述/可链接；⊕ 轨迹＝第二大脑 |
| 机制设计 / 契约理论 | 人判契约 | 移除外部激励→人只剩"对自己诚实"；判定权在人防机器 Opportunism |

**归一句**：盲区环不是凭空设计的，它恰好落在"ZPD 通道里逼人生成、用镜子纠正元理解错觉、以不评分守住内在动机、把知识外置成第二大脑"这一组已被认知科学反复验证的原理交线上；灵境的特有贡献是把这组原理工程化为可运行、且守红线的镜环。
