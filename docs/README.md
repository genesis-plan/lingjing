# 灵境·课室（Lingjing Classroom）

## 一句话介绍
让普通人在虚拟课室中体验「教师」职业的 Web 应用——你讲一节课，5 名学生当堂向你追问；课后你拿到一份「他问的 / 你答的」逐条清单，**答到没由你自己判**，机器只数词、不下结论。

> ⚠️ **2026-09-11 重大变更（诚实口径）**：原产品会计算「AI 学生的理解度 / 知识状态矩阵 P / 教学效果 E / 差异度 σ²」并展示。
> 这些数字源头是「模型采样出的学生自评理解度」或「2-gram 文本重叠噪声判定」——
> **是我们不可能知道的真值，属假理论**，已于本日全部移除、不再计算也不再展示。
> 产品定位回归用户原话：「这是为人服务的，不是为 AI 服务的。」

## 当前状态
- **MVP（文本输入版）已实现并本机验证**：纯前端 + 极简 Node 服务，零 3D / 零语音 / 未部署。
- 数学框架背景：BKT 概率状态 + ReKT 多层面 + 性格驱动 LLM 学生（见 `docs/classroom-framework.md`）。
  其中「学生理解度 P(t) / 教学效果 E / 差异度 σ²」**已于 2026-09-11 停用**，仅作历史框架参考，不再实现。
- ⚠️ 3D 课室 / 麦克风语音 / 多人在线 为 Phase 2 候选，**未采纳**，待用户拍板（属基建税）。

## 技术栈（当前 MVP）
- **前端**：原生 HTML/CSS/JS（`public/classroom.html` 主页面；`public/index.html` 简化体验页）
- **后端**：Node 原生 http（零依赖，`server.js`，SSE 流式）
- **知识模型**：`teaching.js`（纯函数：概念抽取 / 难度估计 / 性格调度）
- **框架世界**：`world.js`（⟨S,R,M,T⟩）
- **LLM**：OpenRouter（默认免费档，有密钥走真实学生提问；无密钥走确定性兜底）

## 快速开始

```bash
# 进入项目
cd lingjing

# 启动（本机）
node server.js
# 浏览器打开 http://localhost:8080

# 可选：真实 LLM 学生（免费档 50 次/天；充值 $10 升 1000 次/天）
LINGJING_OR_KEY=sk-or-xxx node server.js
# 指定模型（默认免费档）
LINGJING_OR_MODEL=xxx node server.js
```

CLI 也可直接跑：
```bash
node teacher.js "课题名::你的讲解[||概念1|概念2]"
```

## 核心数学背景（历史框架，2026-09-11 起停用）
> 以下公式是早期「学生理解度建模」的理论定义，**当前产品不再计算、不再展示**：
- 状态更新：`p'_{i,j} = p_{i,j} + α_i·β_j·LLM_i − γ·p_{i,j}`
- 教学效果：`E = (1/(N·M))·Σ(p'_{i,j} − p_{i,j})`
- 差异度：`σ² = (1/(N·M))·Σ(Δp_{i,j} − E)²`
>
> 原因：`LLM_i` 是模型采样出的「自评理解度」，没有真值来源（GIGO）；`E/σ²` 整条链可信度上限＝LLM 自评可信度。
> 免费/小模型还有谄媚饱和风险。这些数会让人误以为「系统知道 AI 学生懂没懂」，而它并不知道。
> 现改为只上报事实（探测枚数、你回了几个、逐条原文），判断权交还使用者。
