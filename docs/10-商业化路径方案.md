## 1. 一条必须先说的证据：为什么"人在房间里"是硬前提

这是本次查到的**最有商业含义**的一条，比上轮给你的 Khanmigo 数据更硬。

> **凡是有强结果的 AI 教学案例，配置里都有一个真人；凡是 AI 被单独留下陪学生的，参与度崩塌。**

| 配置 | 结果 | 来源 |
|---|---|---|
| AI 单独陪学生 | **每周 2.18 分钟**使用 | Stanford literacy trial |
| 加一个**被禁止教学**的人（只签到、修耳机、问"你在做什么"） | 参与度 **+71%~80%** | 同上（District B 用的甚至是中学生） |
| AI 提示人类导师（ tutor 仍是人） | 掌握度 +4pp / +9pp | Tutor CoPilot RCT（900 导师 / 1800 学生） |
| AI 单独陪 Kahn Academy 学生 | 0.06–0.08σ/学年，研究者自评"与不用 AI 的平台差不多"；中位学生只在约 1/3 练习日发消息；**仅 14.5% 消息含真实数学推理**，近 40% 只是把答案打进去 | Khanmigo 两年整群 RCT（18 校 / 6902 学生-学期观测） |

**这句话要刻在产品上**：
> 求助是一次"承认自己不会"，这在社交上是沉重的。它从来就不是一个模型能力问题——所以模型变强不会自动解决它。

**对我们的直接推论**：镜子要求使用者"先讲出来"，这本身就踩在求助成本最高的地方。**因此产品形态必须自带一个降低求助成本的机制**——要么接入一个真人（路径 A），要么使用者本身就有输出动机（路径 B）。这是两条路径的共同底层逻辑，不是巧合。

> 诚实标注：上述均为**同类产品/研究的证据**，不等于我们的产品有此效果。我们目前**零真人验证** `未验证`。

## 2. 三条路径逐条拆

### 路径 A：B2B2C —— AI 辅助人类教学者（推荐主线，但**救不了 30 天**）

| 维度 | 内容 |
|---|---|
| **客户** | 教培机构 / 家教平台 / 职校 / 考研辅导机构的一线讲师、助教 |
| **谁付钱** | 机构（按席位），非个人 |
| **产品形态** | 镜子**不直接面对学生**，而是坐在教学者旁边：学生讲 → 镜子输出"他哪里没想清楚（可溯源）" + 建议的三个追问 → **由人类教学者决定怎么问** |
| **现有资产复用** | `teacher.js` 的提问引擎 + 11 类探针 + `report-diagram.js` 图式报告 ≈ 已具备 70%，缺**面向机构的多租户/席位/周报/数据导出** |
| **定价锚点** | Tutor CoPilot ≈ **$20/席/年**（约 ¥145）；对照传统教研培训 **$3,300+/人/年** ⇒ 定价区间建议 **¥300–1500/席/年** |
| **获客（被动）** | 机构采购靠案例与熟人背书；可先从 1 家机构做**免费试点换案例和数据** |
| **合规** | 见 §4。B2B 不直接触达未成年学生时，压力显著小于 B2C |
| **工期** | MVP 6–10 周；首笔回款**保守 3–6 个月** |
| **最大风险** | Tutor CoPilot 自己就承认局限：**近端提升没转化成年末考分**；学生感知问卷（关怀感/心智模式）**无显著变化**；两个月的暴露窗口太短。融资/销售周期长，与 30 天跑道不匹配 |
| **成功判据（预注册）** | ① ≥3 家机构付费续用；② 教学者周活跃 ≥60%；③ 教学者主观"比自己问得准" ≥70% |
| **kill 判据** | 6 个月内无 1 家付费 ⇒ 停，转路径 B |

**必须抄的一条作业**：Tutor CoPilot 访谈里，教学者吐槽"建议常常超出年级水平、需要我简化"。**我们的建议也必须允许被改写，且要把决定权留给人类**——这恰好和 A2 不评分同构。

---

### 路径 B：面向"本来就愿意讲"的人群（绕开死结，可个人付费）

| 维度 | 内容 |
|---|---|
| **客户** | 成人自修者、考研/考证、研究生、需要写复盘的专业人士——**特征是本来就在输出** |
| **为什么成立** | 这群人不需要被劝说的话。"讲出来"对他们不是成本，是刚需。直接绕开 §1 的求助成本死结 |
| **产品形态** | 你讲/写完一段 → 镜子还给一张**可溯源的盲区图**（不含评分） |
| **定价锚点** | 2026 中国知识付费市场 **570 亿元**（+18.8%），付费用户 4.32 亿，**人均年知识消费 ¥380**，复购率 >65%；Coursera Plus $399/年  ⇒ 建议 **¥199–499/年**，或单次报告 **¥29–49** |
| **获客（被动，符合您偏好）** | GitHub 公开仓库 + 一篇"为什么我不给你的理解打分"的方法文章 + B 站/小红书/知乎内容沉淀。**注意：抖音教培类目 2026 已改为定向邀约，无资质会被清退，别把鸡蛋放这里** |
| **合规** | 面向成年人的非学科类工具，压力最小。需注意：不得宣称提分/通过率 |
| **工期** | 现有 Web 版本即可上线收款，2–4 周 |
| **最大风险** | **这群人也在直接用 LLM 问答案**。我们的差异化（不给答案 + 苏格拉底）对多数人是**劣势**不是优势——必须精准命中"觉得直接给答案没用"的那一小撮人 |
| **成功判据** | 30 天内 ≥20 个付费用户、次日留存 ≥40% |
| **kill 判据** | 60 天内付费<20 人 ⇒ 停 |

### 路径 C：B2C 直给普通学生 —— **红灯，不建议**

依据：Khanmigo 两年 RCT + Stanford literacy trial 的 2.18 分钟/周。**连 Khan Academy 的品牌与流量都没能让学生开口，我们没有理由认为自己可以。**
若坚持要试，唯一可辩护的形态是**先引入真人角色**（哪怕只是打卡陪伴），本质上就退化成路径 A/B。

---

### 路径 D（我的建议，但**由您决定**）：现金流止血，与主线并行

不看"伟大产品"，只看"哪件能开票的事最快"。三个候选，**按与您主业的偏离度排序**：

| 选项 | 内容 | 偏离度 | 见效 |
|---|---|---|---|
| D1 | 把镜子做成 **¥99 一次性买断的自检工具**（爱发电 / Gumroad / 自建），立刻可收 | 极低 | 2–4 周 |
| D2 | 用 `report-diagram.js` 的 SVG 能力，做**"你的演讲稿/复盘/架构 ⟶ 结构化认知图"的交付服务**，按份计费 | 低 | 1–2 周 |
| D3 | 接与本产品无关的技术交付/咨询外包（快速现金，但消耗您本就不多的 30 天精力） | 高 | 1 周 |

**诚实判断**：D1/D2 在 30 天内能拿到的现金，大概率也只是**延缓而非解决**。跑道问题终究要靠跑道手段解决（这是钱的问题，不是功能的问题）。AI 不替您拍这个方向。

## 3. 实证：把"零实证"补上（**诚实样本量**）

您上轮提"20 人对照实验"。我实算了（α=0.05 双侧，power=0.80）：

| 设计 | 每组合计 | 结论 |
|---|---|---|
| **两组对照 RCT**（d=0.5 / 0.8 / 1.0） | 128 / 52 / — 人 | 要真对照，**至少 52–128 人**，做不到 |
| **配对/前后测**（d_z=0.5 / 0.8 / 1.0） | **34 / 15 / 10 人** | **可行** |
| **20 人拆两组各 10** | power：d=0.8 → **37.8%**；d=1.0 → 55.4% | **＝抛硬币，禁止采用** |
| **20 人配对设计** | 可检出最小 **d_z=0.66**；若真实 d_z=0.8，power **93.1%** | **采用** |

**因此实验方案这样定（可执行）**：
1. **不用对照组**，用**自身前后测**（每个人是自己的对照）——这正是同样的 20 人能吃下大效应的原因；
2. 主指标**唯一且实验前预注册**，建议：*"使用者第三次重述相对第一次的**盲区自陈数**变化"*（连续量，比二元通过率高得多功效）；
3. 提前写死样本量 **n=20**、停止规则（不许中途偷看、不许事后换指标）——peeking 会把真实假阳性率推到远超 5%；
4. 结论必须写成：**"探索性 pilot，效应量大者方向性提示，非因果证据"** ——不许写成"证明有效"。

> 这条必须守：我们整套产品的立身之本就是"不虚报"。如果自己在第一份实证上注水，产品叙事就崩了。
