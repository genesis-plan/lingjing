## 2. 产品概述

### 2.1 背景与问题
普通用户极少有机会站上讲台体验「教师」角色——现有教育产品里用户永远是「学生」。灵境·课室让用户以教师身份讲课，AI 学生听讲、提问、反馈，获得「教」的体验。

### 2.2 产品定位
**一句话定义**：一个让普通人在虚拟课室中体验「教师」职业的 Web 应用。
**核心价值**：用户讲一节课，5 名性格各异的学生当堂向你追问；课后你拿到一份「他问的 / 你答的」逐条清单，**答到没由你自己判**，机器只数词、不替你下结论。

### 2.3 目标用户
- **核心用户**：对教育感兴趣、想体验教师角色的普通人（大学生、职场人、家长）
- **次要用户**：在职教师（教学反思、新方法测试）

## 3. 功能需求

### 3.1 当前 MVP 功能清单（已实现，文本输入版）

| 编号 | 功能 | 描述 | 状态 |
| :--- | :--- | :--- | :--- |
| F01 | 进入课室 | 打开网页即进入课室（纯 UI，非 3D） | ✅ 已实现 |
| F02 | 输入教案 | 文本框输入「课题::讲解」（可选 `\|\|概念1\|概念2`） | ✅ 已实现 |
| F03 | 学生听讲提问 | 5 个学生按性格抛探测、追问（真实文本） | ✅ 已实现 |
| F04 | 教师回答 | 每轮教师回答 / 跳过；产物数出「你回了几枚、还欠几枚」 | ✅ 已实现 |
| F05 | 课后清单 | 「他问的 / 你答的」逐条并列 + 教师专属复盘（费曼/盲区/术语） | ✅ 已实现 |
| F06 | 作品持久 | 教案/笔记/知识态作为 artifact 留世界，不随会话消失 | ✅ 已实现 |

> ⚠️ 原 F05「知识矩阵热力图 / E(t) / σ² 展示」**已移除**（2026-09-11）：这些是假理论数字，不再展示。

### 3.3 非功能需求（当前 MVP）
- 首屏加载 < 1 秒（纯静态 HTML，无 3D）
- 学生响应：无密钥走确定性兜底（瞬时）；有密钥受 LLM 延迟（免费档建议每生 800ms 间隔降限流）
- 支持 Chrome / Edge / Safari（纯前端，无特殊依赖）

## 4. 用户流程（当前 MVP）
```
打开页面 → 输入教案 → 点击"开始上课" → 后端跑课堂循环
→ 5 学生按性格抛探测、教师回答 → 数出「你回了几枚/还欠几枚」
→ 课堂结束：课后清单（他问的/你答的 + 教师复盘）
```
