# 灵境物理约束体系总纲（v1.0）

> 定位：把现实物理约束完整映射进灵境虚拟世界的**体系级设计文档**。
> 原则：① **生成式分类，非平铺清单**——层是生成原则的实例，不是无限加的行；
> ② **数学先行**——形式由定理逼出（量纲/守恒/对称性/因果），系数是数据测的余量；
> ③ **诚实三档**——每项标注【已落】/【路线】/【不做】；
> ④ **fail-closed**——证不出=拒绝或降级为未验证，绝不把不安全说成安全。

---

## 〇、总结构：根系 + 五簇 + 两条横切轴 + 虚拟元层

```
根系（最底层，生成一切随机性与不可逆性）
  ├ 熵增定律            横切红带①：封闭系统混乱度只增不减（Clausius-Duhem 熵产 ≥ 0）
  └ 量子/原子（原L12）    噪声、测量反作用、范德华力/隧穿的源头——它是底层不是顶层

A. 本原物理场（4 种基本相互作用 + 时空）
   A1 时空/运动学（原L1）    流形 ℳ₃,₁；SE(3) 刚体 6-DOF（=此层状态空间维数，非独立层）
   A2 引力/动力学（原L2）    F=ma、动量/角动量守恒（Noether）；电机力=洛伦兹力（接A3）
   A3 电磁（原L7）           麦克斯韦方程组；L8光学/L11通信 = EM 在感知频段的实例
   A4 热（原L5热传导部分）    傅里叶 dQ/dt=−kA·dT/dx + 熵产约束

B. 物质响应（场作用于物质）
   B1 材料/强度（原L3）      σ=C:ε、von Mises σ_vM≤σ_y、疲劳 N_f∝(σ/σ_y)^−k
   B2 接触/摩擦（原L4）      Coulomb |τ|≤μN、Signorini 互补、恢复系数 0<e≤1（含范德华=量子根系）
   B3 流体/气动（原L5流体）   F_drag=½ρCdAv²、升力、N-S 方程
   B4 声振（原L9）           = B3+B1 的机械波：∂²p/∂t²=c²∇²p、模态/共振、阻尼 mx''+cx'+kx=F
   B5 化学/腐蚀（原L10）     Arrhenius k=A·exp(−Ea/RT)、Tafel、老化寿命预测
   B6 环境/气候（原L13）     = A+B+C 在环境尺度上的耦合：温变、湿度、风载、雨雪冰、UV、DEM地形

C. 感知·信息·控制（观测者栈）
   C1 光学/视觉（原L8）      辐射传输、BRDF、针孔模型 x=K[R|t]X、渲染方程
   C2 声学感知（原L9感知面）  混响、超声衰减
   C3 信息/通信（原L11）     时延/丢包/带宽/抖动；无线=EM传播（接A3）；排队论
   C4 测量扰动（量子反作用）  观测即扰动；热噪声/散粒噪声 σ=√N
   C5 控制可观测性【本总纲新增】 闭环稳定：采样 Nyquist、带延迟增益裕度（Bode）；
                             机器人不能对"没感知的"作动且不能发散
   C6 计算能耗下界【本总纲新增】 Landauer：擦 1 bit ≥ kT·ln2——信息-计算约束的物理下界

D. 系统顶层（原L6）
   D1 能量预算      总能耗=运动+计算+热管理 ≤ 总供电；P_in=P_out+P_loss
   D2 热管理        废热 ≤ h·A·ΔT_max，否则必须降功率
   D3 安全/可靠     fail-safe（低电归位）、全应力 < 许用值；变分/MPC 全局优化

E. 虚拟元层（模拟器本身的约束，现实没有）
   E1 因果一致性    事件图必须是 DAG，边 a→b 当且仅当 t(a)<t(b) 且 b∈a 的仿真未来域
   E2 观测裁剪      C=Σ cost(r)·active(r)；暂停区重入须无突变
                    ‖state(r,t_re)−state(r,t_pause)‖<ε（降级≠停止物理）
   E3 时间步进离散  dt ≤ CFL·dx/|v_max|（数值稳定性硬约束，波场尤甚）
   E4 权限/可信边界 世界规则=不可变基线 R₀；UGC脚本=受限 capability，
                    W(script) ∩ W(world_rules) = ∅（现实物体不能自改定律，故此层纯虚拟）

横切红带②：耦合 = 权衡轴
   强度高↔重、散热好↔体积大、功率高↔能耗大——工程权衡不是海森堡不确定性
   （真·海森堡 ΔxΔp≥ℏ/2 属根系，不可逃；工程权衡可取舍但必有代价）。
   任何"我全都要"的规格，沿此带必撞瓶颈约束（见 D 前的联合可行性判定）。
```

**两条根（物理合法性）**：光速上限 = ℳ₃,₁ 光锥 → 同时是 A3 传播上限、C3 时延根源、
E1 因果一致性的物理镜像（虚拟里强制因果 = 复刻现实因果，非凭空规则）。

## 一、联合可行性判定（耦合轴的落地形式）

单律过了 ≠ 系统可行。给定规格 (力F, 速v, 质量m, 特征尺寸L, 占空比)，联立：

| 约束 | 不等式 | 需求尺度 | 容量尺度 | 大 L 趋势 |
|---|---|---|---|---|
| D1 能量 | P ≥ F·v/η | ∝L³ | 储能∝L³ | 须供能跟上 |
| B1 材料 | F ≤ σ_y·A_cs | 自重∝L³ | A_cs∝L² | σ∝L → 自压垮 |
| D2 热 | (1−η)P ≤ h·A·ΔT_max | 废热∝L³ | 散热面∝L² | ΔT∝L → 自烧毁 |
| B3 气动 | 推力 ≥ ½ρCdAv² | 须扛自重∝L³ | 推进∝截面∝L² | 飞不起来 |
| 气动加热 | 加热率 ∝ L²v³，且 v²∝L | — | — | ∝L⁵ → 烧穿 |
| A2 惯性 | 急停力 mΔv/t ∝L³ | ∝L³ | 结构容限∝L² | 急转自撕裂 |
| B1 疲劳 | N_f∝(σ/σ_y)^−k，σ∝L | — | — | 大件更早碎 |

**平方-立方律（统一证明）**：需求∝L³，容量∝L²，比值∝1/L。
巨型人形不可行 = 上表在大 L 处**同时无解**，不是某一条单独崩——这正是横切红带②的结论。
即使给理想无限能源，材料扛不住、热排不掉、气动力不允许，照样锁死。

**判定器接口**【路线】：
```
feasibility(spec) → { feasible: bool, binding: [最先破的约束…], margins: {各约束余量} }
```
耦合结构（尺度律、不等式方向）数学可先验判；系数（σ_y, h, Cd, η, k_fatigue）须实测。

## 四、诚实边界（全程坚持，不得违反）

1. **休谟欠定**：观测结构不可免——看到变形≠知道本构；用反证+互证区分（弹 vs 塑=卸载回零判据）。
2. **信任时域**：系数微差经多次事件累积，误差随时域增长是真实形状，不为过阈值调参。
3. **系数全是余量**：形式推导 ≠ 数值已知；材料牌号/散热系数/腐蚀常数须真实测量。
4. **真实数据卡点**：沙箱无网，LeRobot 真数据待有网机器接入同一管线。
5. **宏观忽略量子/强弱核**是正确近似，注明适用边界，不硬上。
6. **本总纲不是"已形式化证明"的声明**——它是约束映射体系；可审计可复现，非绝对化承诺。
