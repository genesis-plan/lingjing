# 01 · 产品作用

> 灵境是什么、给谁用、怎么运转、边界在哪、对外口径红线。

---

## 一、一句话

**灵境是一间虚拟课室：你（人类）来给 AI 上课，传授任何知识 / 经验 / 技能；
AI 学生负责激发——从各个角度向你提问，逼你把所知的讲清；
课后由你自己判定讲没讲透，并带走你的思考、盲区与总结。**

> 人类是体验者（也是传授者），AI 是激发者（不学习、不评价、不判定），**判定权永远归人**。

---

## 二、角色契约（不可漂移）

| 角色 | 职责 | **不做什么** |
|---|---|---|
| **人类（体验者 / 传授者）** | 讲出自己的知识 / 经验 / 技能；回答学生的追问；**逐条自判"答到了没有"** | 不把判定外包给机器 |
| **AI 学生（激发者 / 镜子）** | 抛探测（真实文本）、照出人类讲解里没讲透的口子 | **不学习、不评分、不声称"懂了"** |
| **判定者 = 人类本人** | 课后读并排清单，心里"咯噔"处即口子 | 机器不代判 |

**架构不变量（代码层强制）**：世界 `World = ⟨S, R, M, T⟩` 中**不存在"学生→分数"关系**；
一切"懂没懂 / 答到了没有"的自动判定，灵境一律不做。

机器只做两件它真做得到的事：

1. 对人类讲解文本做**确定性弱信号检测**（定位可能漏讲的地方）；
2. 把学生原话与先生原话**逐条并排**（镜子）。

---

## 三、课堂形态：**一面镜子**，不是一个班

| 项 | 实情 |
|---|---|
| 上课的学生 | **1 名**（小明 · 好奇型）——2026-09-18 产品定案：**「一面镜子」** |
| 为什么减员 | 人类要的是**一面能照出缝的镜子**，不是一群分角色的学生。角色分工会把注意力从"我的讲解"引到"学生性格"上 |
| 探测角度 | 仍然**多角**：同一名学生按七类探测（反例 / 边界 / 正例 / 区分 / 机制 / 应用 / 落地）轮换出手 |
| 代码里为何还留着另外四个人设 | `PERSONALITIES` 与前端座位表 `CAST` 保留为多生形态的底层与渲染兜底，**当前链路只取第一枚** |

> ⚠️ **口径纠偏**：仓库早期文档（含旧 README）写的是"5 个 AI 学生"。**代码自 2026-09-18 起只启用 1 名**，见 `teacher.js` 的 `PERSONALITIES.slice(0, 1)`。以本文为准。

## 四、最深的价值流程：盲区照见反思环

```
人讲(Teach) ──▶ AI 多角追问(Ask/Probe) ──▶ 人答(Respond) ──▶ 人自判(Judge＝人) ──▶ 带走(思考/盲区/总结)
                  ▲                                                          │
                  └──────────── 下一轮：新问题来自上一轮没答透的口子 ────────┘
```

| 环节 | 发生什么 |
|---|---|
| **Teach** | 人类注入任意知识 / 经验 / 技能（引擎不生成其内容） |
| **Ask / Probe** | 七类探测轮换出手，由学生产出**真实文本** |
| **Respond** | 人类回话，原文回填到对应探测 |
| **Judge** | **只发生在人脑**：课后逐条读并排清单 |
| **带走** | 课堂纪要 + 讲授收获 + AI 理解笔记 + 跨课无知地图 |

**深度指标（不评分，只计数 / 看增长）**：单课探测构成 + 课后总结（你自己写的）+ 跨课个人无知地图增长。

## 五、给谁用

| 对象 | 怎么用 | 得到什么 |
|---|---|---|
| **想把经验讲清楚的人** | 打开课室，讲一段你熟悉的东西，回答追问 | 照出自己没讲透的口子（自己的，不是别人的） |
| **想验证"自己懂了没"的人** | 用"教"来测自己（费曼式） | 卡壳处的暴露 —— 不是分数，是你自己读到的咯噔 |
| **隐性经验持有者**（手艺 / 判断 / 决策） | 用案例 / 边界 / 权衡类提问被追问 | 把说不清的直觉逼成可描述的表达 |
| **教学 / 学习科学研究者** | 观察"不评分、只提问"的架构如何落地 | 一个可跑、可复现的对照物 |
| **团队 / 教育机构** | 自托管部署（自带密钥） | 不把判定权交给算法的训练场景 |

## 六、能做什么（已落）

- **一面镜子（小明 · 好奇型）**：唯一提问者，每轮都开口，按薄弱点定向出手
- **七类探测**：反例 / 边界 / 正例 / 区分 / 机制 / 应用，外加**落地**（专治口号式空话——把先生原话原样举起来，问"这到底什么意思、拿件具体的事说明白"）
- **确定性薄弱点定位层**：对人类讲解文本做可解释、可复现的弱信号检测（5 类信号：用术语未解释 / 逻辑跳跃 / 具体→抽象 / 照本宣科 / 该讲未讲）→ 决定"哪枚探测去逼哪个口子"
- **确定性提问引擎（TCMQ）**：问句规格（钉谁 / 什么类型 / 引哪句原话 / 第几层 / 什么姿态）全部本地生成，**LLM 只当"嗓音"**
- **AI 理解笔记**：确定性镜子，把"学生听到的 / 还没懂的 / 可能理解偏的"暴露回人类
- **双稿制反思**：AI 镜稿（学徒草稿）→ 人五类修改（确认 / 改写 / 补充 / 删除 / 转化）→ 人定稿（照镜札记）
- **课前"生产性失败"**：先让你尝试、再讲解，并对"现在放行讲解是不是浪费这次失败"给出确定性判断
- **课后卡片 + 跨课知识库**：卡面是**学生当初问你的那句话**（逼主动回想），排期按 FSRS 记忆模型
- **课堂节奏曲线**：画的是"第 k 轮之后你回了多少个字"—— 你写下的字，数得出来，不需要任何判定
- **两个课室形态**：2D 课室（`/`）+ 3D 课室（`/classroom3d.html`，Three.js 已本地化，离线可用）
- **多 LLM 提供商**：OpenRouter（默认）/ 智谱 / DeepSeek / 硅基流动，可切境内提供商

## 七、不做什么（诚实边界）

| 事项 | 实情 |
|---|---|
| **不评分、不判定、不纠错** | 世界模型里没有"学生→分数"边；"你答到了没有"从不由机器决定 |
| **不声称知道 AI 学生的内部状态** | 我们不知道一个 AI 学生有没有"悟"（它没有脑子），所以从不声称知道 |
| **不做情感依赖** | 不诱导"离不开 / 想你 / 需要你"；界面明确提示"在与 AI 而非自然人交互" |
| **研究引用 ≠ 产品复现** | 文档引用的教学研究是我们的**设计依据**，不是"我们已达到该效果"的证据 |
| **AI 学生由大模型扮演** | 它的价值不在"它学会了"，而在"它问出的东西能不能让你发现自己没讲透" |
| **无大模型也能跑** | 未配置密钥时走确定性兜底语料（体验降级，流程仍完整） |
| **没有账号、没有鉴权、没有公网服务** | 定位为自托管（clone 后本机 / 内网跑）；公网运营须先过合规清单（见 [06](06-许可与合规.md)） |
| **仓库公开可见 ≠ 授权使用** | 当前 UNLICENSED，保留所有权利（见 [06](06-许可与合规.md)） |

**关于自动判定：我们撤销过。** 详见 [03 · 设计思想](03-设计思想.md) 第五节 ——
这不是"暂时没做"，是**试过、标定发现是噪声、主动删掉**。

---

## 八、对外口径红线

1. 说"照出你的盲区"，**不说**"知道你答到了没有"。
2. 说"学生由大模型扮演"，**不说**"AI 学生学会了"。
3. 说"研究引用是设计依据"，**不说**"达到论文效果"。
4. 说"不评分是架构不变量"，**不说**"比竞品更有教育效果"。
5. 说"**一面镜子**"，**不说**"五个学生各有性格"（已成为历史形态，见第三节）。
6. **绝不**出现"AI 已吃透 / 理解度 37%"这类把模型采样值说成观测的表述。
7. 课堂现场只出现人能一眼懂的东西；一切内部指标收进课后抽屉，默认不展开。
