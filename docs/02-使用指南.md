# 02 · 使用指南

> 怎么把它跑起来、怎么接大模型、怎么自己验证真实基线、以及踩过的坑。

## 一、依赖与环境

| 项 | 要求 |
|---|---|
| Node | **22+**（实测 22.12） |
| 第三方依赖 | **零**。只用 Node 内置模块与浏览器标准 API |
| 浏览器 | 任意现代浏览器（3D 课室需 WebGL；Three.js 已本地化为 `public/three.module.js`，**离线可用**） |
| 操作系统 | 不限（Windows / macOS / Linux 均可） |

```bash
git clone https://github.com/genesis-plan/lingjing.git
cd lingjing
```

## 二、三种起法

### ① 完全不配密钥（推荐先跑这个）

```bash
node server.js
```

浏览器打开 <http://localhost:8080>。

- AI 学生走**确定性兜底语料**（`PERSONA_FB`）：流程完整、体验降级。
- **全程零外发**：讲解内容不出本机。数据合规要求高的场景就用这个模式。

### ② 配一个大模型（让学生说人话）

```bash
# 默认 OpenRouter（境外）
LINGJING_LLM_PROVIDER=openrouter LINGJING_OR_KEY=sk-or-v1-xxx node server.js
```

Windows PowerShell 写法：

```powershell
$env:LINGJING_LLM_PROVIDER='openrouter'; $env:LINGJING_OR_KEY='sk-or-v1-xxx'; node server.js
```

### ③ 换端口 / 换提供商

```bash
PORT=9090 node server.js
LINGJING_LLM_PROVIDER=zhipu LINGJING_ZHIPU_KEY=xxx node server.js
```

## 三、环境变量全表

| 变量 | 默认 | 作用 |
|---|---|---|
| `PORT` | `8080` | HTTP 端口（注意：是 `PORT`，不是 `LINGJING_PORT`） |
| `LINGJING_LLM_PROVIDER` | `openrouter` | `openrouter` / `zhipu` / `deepseek` / `siliconflow`（无法识别时回退 `openrouter`） |
| `LINGJING_OR_KEY` | — | OpenRouter 密钥 |
| `LINGJING_OR_BASE` | `https://openrouter.ai/api/v1/chat/completions` | OpenRouter 端点 |
| `LINGJING_OR_MODEL` | 免费档降级链 | 指定 OpenRouter 模型 |
| `LINGJING_ZHIPU_KEY` / `_BASE` / `_MODEL` | — / `open.bigmodel.cn/api/paas/v4/chat/completions` / `glm-4.7-flash` | 智谱 |
| `LINGJING_DEEPSEEK_KEY` / `_BASE` / `_MODEL` | — / `api.deepseek.com/v1/chat/completions` / `deepseek-chat` | DeepSeek |
| `LINGJING_SILICONFLOW_KEY` / `_BASE` / `_MODEL` | — / `api.siliconflow.cn/v1/chat/completions` / `deepseek-ai/DeepSeek-R1-0528-Qwen3-8B` | 硅基流动 |
| `LINGJING_SF_CHAT` / `_REASON` / `_TRANSLATE` / `_ASR` / `_IMAGE` / `_OCR` / `_SAY` | 见 `llm.js` | 按功能指定模型（译 / 推理 / 对话 / 识别 / 生图 / OCR） |
| `LINGJING_LLM_BUDGET_MS` | 见 `llm.js` | 单次 LLM 调用时间预算（超时即降级到兜底语料） |
| `LINGJING_DIAG` | 关 | 打开 LLM 诊断日志 |
| `LINGJING_BLOCKLIST` | — | 访问黑名单（`server.js`） |

> 🔐 **密钥只放服务端环境变量**，从不进前端、不进仓库。`LINGJING_OR_KEY` 这类凭证已经被 `.gitignore` 的 `credentials*.md` / `.env` 规则兜住，但**请自己再确认一遍**。

## 四、HTTP 接口（速查）

完整表格与协议要点见 [04 · 技术参考](04-技术参考.md#十http-接口)。课堂用 **SSE（`text/event-stream`）** 流式推送。

| 方法 | 路径 | 一句话 |
|---|---|---|
| `GET` | `/` | 2D 课室 |
| `GET` | `/classroom3d.html` | 3D 课室 |
| `GET` | `/api/roster` | 学生人设（**当前只返回 1 名**：小明） |
| `POST` | `/api/class/start` | 开课（SSE：`start` + 第 1 轮） |
| `POST` | `/api/class/reply` | 老师回话，推下一轮，末轮自动 `done` |
| `POST` | `/api/teach` | 一次性跑完整堂（SSE） |
| `GET` | `/api/world/:name` | 取回持久化的世界对象 |
| `POST` | `/api/llm` | 按功能组合的文本 / 视觉调用（`fn`） |
| `POST` | `/api/image` | 文生图 |
| `POST` | `/api/asr` | 语音识别 |

**无鉴权、无限流** —— 只在本机 / 内网跑，别直接暴露到公网（见 [06](06-许可与合规.md)）。

## 七、常见问题

**Q1：跑起来学生说的话很机械 / 像复读？**
没配密钥或在走兜底语料。配 `LINGJING_LLM_PROVIDER` + 对应 key 后**重启服务**（环境变量是启动时读的）。

**Q2：学生老说同一句话 / 台词不跟着我的输入变？**
历史上有过一个根因：熔断时间戳解析把"秒级时间戳"当成"毫秒"，于是封禁时间被算到几万年后，永久走兜底。**已修**（`test_llm_wiring` 的 `【5】` 两条断言守护这一点）。若复现，先看 `LINGJING_DIAG=1` 的诊断输出。

**Q3：为什么只看到一名学生（小明）？另外四个呢？**
产品 2026-09-18 定为「**一面镜子**」，只启用第一名人设。`PERSONALITIES` 与前端 `CAST` 里保留五个人设，是多生形态的底层与渲染兜底。详见 [01 · 产品作用](01-产品作用.md#三课堂形态一面镜子不是一个班)。

**Q4：它能给我打分 / 告诉我哪里没讲好吗？**
**不会，也不打算会。** 世界模型里没有"学生 → 分数"边。它只做两件事：定位可能漏讲的位置（确定性弱信号检测）、把你的话与学生的原话并排。判定权归你。详见 [03 · 设计思想](03-设计思想.md)。

**Q5：能放到公网上给团队用吗？**
可以放**内网**（自己加反向代理与访问控制）。**公网**还不行：无鉴权、无限流、无备案、无存储 TTL —— 清单见 [06 · 许可与合规](06-许可与合规.md#四公网运营前必须补的清单当前未做)。

**Q6：`docs/` 里的文档跟代码不一致怎么办？**
以**代码 + [04 · 技术参考](04-技术参考.md)** 为准。`09` / `10` 两篇是**归档的设计期框架文档**，开头有状态说明，数字可能滞后。

**Q7：为什么没有 CI / npm 包 / Release？**
刻意没有。当前无版本号体系（原因见 [07 · 版本管理](07-版本管理.md)），仓库即自托管发布。

## 八、内网部署备忘

1. 用 `PORT` 指定端口，前置 Nginx / Caddy 反代。
2. **加上访问控制**（Basic Auth 或内网白名单）—— 服务自身没有鉴权。
3. 密钥放**服务端**环境变量，别写进任何前端文件。
4. `sessions/` 定时清理。
5. 若要走公网，先过 [06](06-许可与合规.md) 的合规清单。
