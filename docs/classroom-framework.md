## 一、核心思想：三个来源的融合

| 来源 | 核心思想 | 如何融入 |
| :--- | :--- | :--- |
| **贝叶斯知识追踪 BKT** | 学生知识是隐藏状态，用可观测表现推断；二值（掌握/未掌握） | 用概率 `p_i(t)∈[0,1]` 表示 AI 学生对知识点的掌握概率（连续化） |
| **BKT 遗忘参数** | 知识可遗忘，从已掌握跳回未掌握 | 状态更新引入遗忘因子 `γ` |
| **ReKT(2024)** | 问题-概念-领域三层建模；Forget-Response-Update 框架 | 每个学生对每个知识点维护独立掌握概率；按教学交互更新 |
| **LLM 学生模拟** | 用 LLM 模拟推理路径与错误模式；性格驱动代理 | 5 种性格 Prompt 驱动学生行为差异，非复杂数学模型 |
| **可控学生模拟** | 显式技能向量控制掌握程度 | 初始掌握概率由性格 + 难度共同决定 |

## 二、五个定义 + 一个假设（实现映射）

**定义1 知识点空间** `𝒦={k_1..k_M}`，MVP `M≤5`。
→ 代码：`extractConcepts()`——可选显式给（`课题::讲解||概念1|概念2`），否则按句自动抽 ≤5。

**定义2 知识状态** `p_{i,j}(t)=P(学生 i 已掌握 k_j @ t)∈[0,1]`；矩阵 `P(t)∈[0,1]^{N×M}`，`N=5`。
→ 代码：`initP()` 由 `α_i`（性格）× `(1−β_j)`（难度）定初值。

**定义3 教学行为与状态更新**
`p_{i,j}(t+1)=p_{i,j}(t)+Δp_{i,j}−γ·p_{i,j}(t)`，
`Δp_{i,j}=α_i·β_j·LLM_i(教学内容,k_j)`，
`γ=0.05`（每轮遗忘 5%）。
→ 代码：`assess()`（有密钥走 LLM 自评，无密钥走 `fallbackUnderstand` 确定性递增）+ 主循环按式更新。

**定义4 教学效果度量【⛔ 2026-09-11 已停用】**
`E_j(t)=mean_i(p_{i,j}(t+1)−p_{i,j}(t))`，
`E(t)=mean_{i,j}(Δp)`，`σ²(t)=mean_{i,j}(Δp_{i,j}−E(t))²`。
σ² 大 → 提示「理解差异大，建议复讲」。
→ 代码：原 `teachingEffect()` 每轮返回 `E / Ej / σ²` 并渲染热力图——**该函数已停用（2026-09-11），不再调用、不再渲染**。

**定义5 提问生成** `Question_i(t+1)=LLM_{性格_i}(教学内容, p_{i,:}, 历史)`，5 性格各有提问风格。
→ 代码：`studentQuestion()` + `PERSONA_FB` 兜底语料（5 组各 3 条）。

**核心假设**：LLM 能按 Prompt 模拟不同性格学生的学习行为、知识变化与提问风格。
→ 验证方式：观察 5 学生在性格上是否可区分、状态变化是否合理、提问是否相关（内部测试已确认，但受模型质量影响）。

## 三、教学循环（Teach 操作）

`Teach: (T, P(t), 性格) ↦ (P(t+1), Q(t+1), E(t), σ²(t))`
- 输入：教学内容 T（文本）、当前 5×M 矩阵、5 性格标签
- 输出：更新后矩阵、5 个学生问题、整体效果 E、差异度 σ²
- 每轮 10 次 LLM 调用（5 评估 + 5 提问）+ O(N·M) CPU。MVP 完全可行。

## 五、⚠️ 诚实局限性（务必记住，别把软度量当诊断）

1. **`LLM_i` 是软度量，非客观校准概率。** 整条 `Δp→E→σ²` 链可信度上限 = LLM 自评的可信度。免费/小模型有**谄媚饱和**风险：若总回 ≈1，P 几轮锁 1、E(t) 虚高但空洞。→ E/σ² 在 MVP 仅作「相对变化信号」，不当客观测评。v2.0 才引入客观测试。
2. **`γ·p(t)` 遗忘项在短课可忽略**：单会话 <30 分钟、4 轮，E(t) 大概率恒正，σ² 的「差异大建议复讲」信号弱——阈值需真人使用后校准。
3. **知识点自动抽取是启发式**（按句切分），非真概念分割；显式给概念更准。
4. **概念独立假设**（无知识依赖）对多步课不成立；v1.3 才引入知识图谱。
5. **5 学生共享同一 LLM**：性格差异仅靠 Prompt，成本最低；验证 PMF 后考虑微调。
